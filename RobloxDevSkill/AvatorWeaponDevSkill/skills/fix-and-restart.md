# Fix and Restart

コード修正後にRoblox Studioでテストする標準手順。

## 手順

// turbo-all

1. ゲームが実行中の場合、MCPで停止する
2. Rojo/Argon sync でコード変更を Studio に反映する
3. `RoundSystem.server.luau` が `Disabled=true` であることを確認する
4. MCPでゲームを開始する
5. コンソール出力を確認し、エラーがないかチェックする

## 確認項目

- SafeZone に入るとマッチが開始されること
- モード投票UIが表示され、投票できること
- 料理画像が表示されること
- 地図上にピンを設置できること
- 回答送信後にラウンド結果が表示されること（距離、スコア、ピン）
- 全ラウンド終了後に最終結果画面が表示されること
- AI詳細ウィンドウが表示され、料理の説明が読めること
- リーダーボードが正しく表示されること
