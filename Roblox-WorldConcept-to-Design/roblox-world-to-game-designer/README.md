# Roblox World-to-Game Designer Skill

ユーザーが提示した世界観、キャラクター幻想、映像イメージ、必須アクションなどを、Roblox向けの「必要最小限のゲームデザイン仮説」に変換するSkillです。

## 主な用途

- 世界観から1つのゲームカテゴリとコアループを設計する
- 同じ世界観を別ジャンルへ再設計する
- 指定された攻撃・能力を、役割の異なるゲームメカニクスに変える
- 新規性を見た目ではなくゲーム構造として説明する
- 最小プロトタイプと一次評価を作る
- 面白さが未検証の段階で巨大GDD化することを防ぐ

## 導入

`roblox-world-to-game-designer` フォルダを、利用するエージェント環境のSkillsディレクトリへ配置してください。主要な指示は `SKILL.md` に完結しています。

## 呼び出し例

```text
この世界観をRobloxゲーム化して：
「プレイヤー自身が巨大ボスになる」
まず面白さを判断したいので、1つの必要最小限のゲーム案だけ提示して。
```

```text
前案とは別のゲームカテゴリで再設計して。
```

```text
巨人には下方パンチ、かかと落とし、目からビーム、火炎放射を必ず持たせたい。
これらが単なるダメージ技にならないゲーム案を考えて。
```

## 設計思想

- 世界観はゲームそのものではなく、遊びを生む素材として扱う
- 入口は理解しやすく、中心体験は新しくする
- 最初は一案に絞り、コアループと試作仮説を明確にする
- 見た目だけでなく、目的・関係・リスク・セッション構造のどこかを新しくする
- 課金・収集・大量コンテンツより先に、操作と判断の面白さを検証する
