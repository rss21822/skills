# Historical evaluation provenance

The exact prompts used for this historical fresh-project run were not retained. The generated `eval-review-fresh.html` therefore displays `(No prompt found)` and is not a fully auditable review artifact.

Do not reconstruct or infer the missing prompts. Preserve the grading/output JSON as historical evidence only. The current prompt definitions are retained explicitly in `../evals/evals.json`, schema version 2, and future runs must copy the exact prompt plus model, skill path, commit/hash, timestamp, and metrics into each run directory.
