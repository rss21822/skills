# 剣の 3 連撃（袈裟斬り → 横薙ぎ → 振りかぶり叩きつけ）仕様

対象リグ: `rig-r15.json`（R15、Motor6D の C0/C1 は全関節で回転なし、hipHeight 2.2248、HRP 2×2×1）。
正本は `src/SwordCombo/ComboData.luau`（`tools/bake_combo.luau` が生成）。5 章の表は `tools/spec_tables.luau` で ComboData から機械的に出したもので、手書きしていない。

## 1. 座標と符号の規約

| 項目 | 規約 |
|---|---|
| 書き込む値 | `Motor6D.Transform`（C0 の座標系）。`Part0.CFrame * C0 * Transform == Part1.CFrame * C1` |
| 軸 | 本リグは C0/C1 の回転が単位行列なので **関節の軸 = キャラの軸**: +X = キャラの右、+Y = 上、**-Z = 前** |
| 回転の順序 | `CFrame.Angles(rx, ry, rz)`（= Rx·Ry·Rz）。表の値は **度** |
| X+ | 下向きの骨を **前へ振り上げる**（肩 X+ = 腕が前へ上がる / 肘 X+ = 前腕が前へ曲がる = 屈曲）。上向きの骨（Waist・Neck）では **X+ = 後ろへ反る、X- = 前へ屈む** |
| Y+ | 上から見て反時計回り = **キャラの左へひねる**（Waist Y- = 右へひねる） |
| Z+ | 下向きの骨を +X（右）側へ: **右腕なら外へ開く、左腕なら体の内側へ寄る**。Waist/Neck では **Z+ = 左へ傾く** |
| 膝・肘 | 膝は X- で曲がる（下腿が後ろへ）。肘は X+ で曲がる。右肘の X は 0〜145 に制限（過伸展なし） |
| Root | `{rx, ry, rz ; px, py, pz}`（度 ; stud）。py- = 骨盤が沈む、pz- = 骨盤が前へ出る（体重移動） |
| 剣 | 右手の握り点 = RightHand 空間 (0, -0.15, 0)。**刃の向き = RightHand の -Z**（Roblox 既定の Tool の持ち方と同じ）。握り点→切っ先 4.0 stud |
| 両手持ち | 左手の握り点 = 右手の握り点から刃と逆向きへ 0.50 stud（柄頭側） |
| 地面 | HRP 中心から y = -3.2248（hipHeight + HRP 半高） |

Neck は「上体のひねり・前後傾を首で打ち消して目線を標的に残す」規則で生成:
`Neck = (-0.5·(Root.rx+Waist.rx), -0.7·(Root.ry+Waist.ry), -0.6·(Root.rz+Waist.rz))`。

## 2. レイヤー構成（既定の Animate と共存）

| 部位 | 関節 | 攻撃中の扱い | 備考 |
|---|---|---|---|
| 上半身 | Waist, Neck, 両 Shoulder/Elbow/Wrist | 表の値で上書き（重み 1）。終了後 0.20 s で Animate の姿勢へフェード | 開始キー（t=0）は押した瞬間に見えている姿勢 = 跳ばない |
| 骨盤 | Root | 静止中のみ表の値（重み 1）。歩行中・空中は 0.12 s で重み 0 へ | 沈み込み・前後の体重移動・小さなひねり |
| 脚 | Hip, Knee, Ankle | 表には無い。**実行時の 2 関節 IK** で足首を静止時の位置・向きに固定（骨盤だけ動かして足は床に残す） | 歩行中・空中は Animate の脚のまま |
| 左腕（3 撃目） | LeftShoulder/Elbow/Wrist | 表の値（オフライン IK で柄に合わせ焼き込み済み）＋ `左手IK=1` の区間は実行時 IK で柄頭へ吸着 | IK→FK の受け渡しは t=0.80 の「左手IK=0」キー |

書き込みタイミング: `RunService.PreSimulation`（Animator のアニメーション段階の直後）。Animator が書いた値を基準（base）として `base:Lerp(レイヤー値, 重み)` を書く。

## 3. 時間の設計（重さの付け方）

各段とも「予備動作（ゆっくり入る inOutSine）→ 溜め（ほぼ静止）→ 振り（inQuad で加速、頭の横/前を通す中間キー）→ 当たり（linear）→ フォロースルー（outQuad/outCubic で減速し、少し戻る余韻キー）→ 戻り」。

| 段 | 予備動作 | 溜め | 振り〜当たり | フォロースルー | 戻り | 合計 | ヒットストップ |
|---|---|---|---|---|---|---|---|
| 1 袈裟斬り | 0.00–0.15 | 0.15–0.20 | 0.20–0.27 | 0.27–0.42 | 0.42–0.64 | 0.64 s | 0.07 s（約 4 f@60） |
| 2 横薙ぎ | 0.00–0.14 | 0.14–0.19 | 0.19–0.25 | 0.25–0.44 | 0.44–0.66 | 0.66 s | 0.08 s（約 5 f@60） |
| 3 叩きつけ | 0.00–0.32（柄を取る→頭上へ） | 0.32–0.40 | 0.40–0.49 | 0.49–0.80（反動→沈み→左手離し） | 0.80–1.08 | 1.08 s | 0.14 s（約 8 f@60） |

- 連撃入力: 各段の開始 0.10 s 以降の入力を先行入力として保持し、`chainAt`（1 撃目 0.42 s / 2 撃目 0.44 s）以降に次段へ移る。次段の t=0 は移行直前の姿勢そのもの。入力が無ければ戻りまで再生して 0.20 s でフェードアウト。
- 当たり判定区間（`active`）: 1 撃目 0.215–0.330 s、2 撃目 0.200–0.310 s、3 撃目 0.440–0.530 s。区間内で最初に当たったフレームでヒットストップ（1 撃 1 回）。
- 3 撃目は `groundImpact = true`: 刃先が地面（Humanoid 以外）に当たってもヒットストップ。

## 4. ヒットストップ

| 項目 | 仕様 |
|---|---|
| 発火 | 当たり判定区間中、刃（握り点から 20%〜100% の 6 点）の「刃そのもの」と「前フレーム→今フレームの掃引」レイキャストが他の生きた Humanoid（3 撃目は地面も）に当たった最初のフレーム |
| 停止 | アニメ時計を `hitStop` 秒止める。全関節の姿勢は完全に同一。余った dt は停止明けにそのまま進める（フレームレート非依存） |
| 微振動 | 停止中のみ右肩に `1.2°·(残り時間/全体)·sin(2π·32Hz·t)`（X 軸）とその半分（Z 軸）。`hitShake=false` で無効 |
| 通知 | `onHit(段, 当たった Instance, 位置, hitStop秒)`。被弾側の停止・SE・カメラ揺れはゲーム側で足す |
| アップロード後 | `KeyframeMarker "Hit"`（Value=停止秒）を付けて書き出す。AnimationTrack では `track:AdjustSpeed(0)` → 停止秒後に元の速度（`KeyframeSequenceExport.hitStop`） |
