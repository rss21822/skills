# R15 剣 3連撃 — 関節角とタイミングの仕様

正本は `src/shared/SwordCombo/Spec.luau`（この文書の表はそこから自動生成した値をそのまま載せている）。
リグは `rig-r15.json`（R15 ブロック体、HipHeight 基準の立ち足高さ −3.22 stud）。0.8 / 1.0 / 1.3 倍の体格でも同じ仕様（距離はすべて脚長 1.883 stud 比で拡縮）。

## 1. 符号と記法（必読）

- 角度は各関節の **Transform の回転** `CFrame.Angles(rad(x), rad(y), rad(z))`（= fromEulerAnglesXYZ）を度で書く。キャラクターは −Z を向く（右 = +X）。
- 下の符号は **このリグの C0/C1 で順運動学（FK）を計算して確かめた**もの（`tests/test_sword_combo.luau` §1 の 7 契約）。

| 関節 | + の向き（単軸で回したとき） |
|---|---|
| Root | +X 後ろへ反る / +Y **左**を向く / +Z キャラの**左**へ傾く。`dy` は骨盤の高さ（stud、− = 沈む） |
| Waist | −X 前傾 / +X 反る / +Y 胸が左を向く / +Z 左へ傾く |
| Neck | +X 見上げる / +Y 左を向く |
| Shoulder | +X 腕を前・上へ / Z: 右 + ・左 − で腕を横へ開く |
| Elbow | **+X で曲げる**（腕を下げた状態で手が前へ）。Y = 前腕のひねり（回内・回外） |
| Wrist | X / Z で手（刃）の向きを起こす・倒す（刃の向きは下記の刃の仮定で FK 計算） |
| Hip / Knee / Ankle | Hip +X 腿を前へ / Knee −X 曲げる / Ankle +X つま先を上げる（脚は IK が解く。§4） |

- **注意（スキル資料との食い違い）**: スキルの `r15-rig.md` は「Elbow −X で曲げる」と書くが、このリグの FK では Elbow +30° で手が前へ 0.41 stud（z −0.305 → −0.719）、−30° で後ろへ 0.51 stud（→ +0.208、過伸展）。本仕様は +X = 屈曲で作った。Studio で単軸 ±30° のホールドポーズを 1 回撮って確認すること（REPORT の手順 S1）。
- 大きな角度は Euler 3 成分が絡むので直感で読まない。腕のキーは「胸（UpperTorso）空間での手の位置と刃の向き」を目標に `tools/solve_arm_keys.luau` で数値解した（solver 出力時点で手の位置誤差 ≤ 0.14 stud、刃の向き誤差 ≤ 22°）。その後、1撃目の振り終わり・フォロースルーの RightWrist X だけは刃先が床に入らないよう数値走査で変えた（−67→−82、−63→−76。刃先の最低点は床上 0.028 stud）。
- **刃の仮定**: 刃 = RightHand の −Z 方向、長さ 3.2 stud（既定 Tool の握りで拳の前へ刃が出る形）。実際の `Tool.Grip` が違えば、solver の目標を変えて解き直す（手首の値が主に変わる）。

## 2. 全体の構造

- 1 撃ごとに **予備動作（逆へ溜める）→ 間（溜めの頂点で一瞬ゆっくり）→ 振り（ease-in で加速、接触で最速）→ 振り終わり（ease-out）→ フォロースルー（行き過ぎ）→ 戻り**。
- 重さの数値（手の速さ、root 空間、60 fps）: 予備動作の最高速 → 接触までの最高速 = 1撃目 33.9 → 96.0 stud/s（2.8 倍）、2撃目 21.8 → 61.0（2.8 倍）、3撃目 14.7 → 86.3（5.9 倍）。溜めは遅く、振りは速い（契約: 2 倍以上）。
- 3 撃は流れでつながる: 袈裟斬りは左下で終わる → 横薙ぎはそこからさらに左へ巻いて（予備動作）左→右に振る（逆手の横薙ぎ）→ 右上に残った剣を振りかぶって正面へ叩きつける。前の撃の「戻り」キー = 次の撃の開始キー。
- 3 撃目の頂点で左手が柄に添う（両手、左手は柄頭側 0.45 stud、解の誤差 ≤ 0.06 stud）。

## 3. 撃ごとの関節角とタイミング

## 4. 脚と足（接地）

- 脚はキーを持たない。**足は root（HumanoidRootPart）空間の固定目標**で、毎フレーム二関節 IK（`Player.solveLeg`: 膝は長さ、股関節は最小の振り＋膝がつま先の方向を向くひねり、足首で足の向きを合わせる）で解く。骨盤（Root）が巻く・沈む・反るほど膝と股関節が自動で曲がり、**足は 1 mm も動かない**（IK 誤差 7.4e-7 stud）。
- 構え（stance）: 左足を前へ 0.50・内へ 0.05 stud、つま先を外へ 12°（+Y）。右足を後ろへ 0.42・外へ 0.08 stud、つま先を外へ 32°（−Y）。高さは立ち足と同じ（床の上）。
- 足が動くのは踏み替えの**持ち上げた弧**だけ（床の近くでは横に動かない: 前後 15% は真上・真下だけ、中 70% で水平移動、高さ = lift·sin(πu)）:

| 踏み替え | 足 | 時刻（撃の時計 / 終了からの経過） | 持ち上げ |

| 構えへ入る（1撃目の予備動作中） | 左 | 0.00–0.14 s | 0.16 stud |
| 〃 | 右 | 0.05–0.19 s | 0.10 stud |
| 3撃目の踏み込み（叩きつけと同時に着く） | 左、前へ 0.30 stud | 0.32–0.47 s（接触 0.47 s に着地） | 0.20 stud |

## 5. ヒットストップ

- 止めるのは**描画のポーズ時計だけ**。物理・Humanoid・入力・Animator・他の体は止めない（Player/Layer はそれらに触れない）。
- 長さ（実時間）: 1撃目 0.06 s、2撃目 0.07 s、3撃目 0.12 s（60 fps で約 4 / 4 / 7 フレーム）。
- ヒットが接触時刻より前に分かっている（予測・サーバー確定・プレビュー）なら、時計を**接触時刻ちょうど**で止める（フレームの途中でも接触時刻に合わせ、余りはヒットストップに充てる → 30 / 60 / 144 fps で停止時間が 1e-6 s 以内で一致）。接触後 0.05 s 以内に届いた確定は、その場で止める。それより遅い確定では止めない（止めると別の姿勢で止まって見える）。
- 止まっている間の揺れ: 右肩 X に ±shake°（1/60 s ごとに符号反転、残り時間に比例して減衰）、左肩に 0.6 倍、Waist Y に 0.5 倍。1撃目 ±0.8°、2撃目 ±0.8°、3撃目 ±1.6°。
- 止まっている間は次撃への連結・終了もしない（明けてから）。

## 6. 連撃の受付と遷移

- 受付: 撃の時計が `inputOpen` 以降の押下を 1 回だけバッファ（それより前の連打は捨てる）。1撃目 0.28 s〜、2撃目 0.18 s〜、3撃目は最終撃。
- 連結: バッファがあれば `chainAt`（1撃目 0.60 s、2撃目 0.50 s = フォロースルーの行き過ぎの後）で次撃の 0 s から開始（chainAt を超えた分の時間は次撃へ持ち越す）。
- 遷移はすべて**描いている姿勢から**始め、出ていく動きの速度を運び（`Kit.carriedStart`）、補間の上に「作者の動き + 360°/s」の上限（`Kit.carryLimit`）を掛ける:

| 遷移 | 補間の長さ |
|---|---|
| Animate → 1撃目 | 0.10 s（その後 1撃目の予備動作 0.28 s が続く） |
| 撃 → 次の撃 | 0.08 s |
| 最終撃 → Animate | 0.28 s（上半身・Root）＋脚の残差 0.08 s（Root が戻り切ってから） |

- 解放: 全関節が Animate の値と 0.05° 以内になったフレームで書き込みをやめる（1 フレームで跳ばない）。
