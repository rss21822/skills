## 1. 読み方（6 軸）

モチーフを一文の雰囲気で受け取らず、画面の部品に落ちる言葉へ分解する。各軸 1〜2 語で書き出せば十分。

- **素材** — そのモチーフの世界で「看板」や「札」は何でできているか。紙のステッカー / 飴細工 / 木札 / 和紙の提灯 / 羊皮紙と封蝋 / ネオン管と金属板 / 布のワッペン / 石板。パネルの色（紙の色）、縁の色と太さ、艶（gloss）の有無、影の出し方が決まる。
- **形** — 丸い（飴・泡・ぬいぐるみ）/ 角が立つ（金属・結晶）/ 手描きで揺れる（傾き ±2〜4°）/ 切り欠き（チケット・札）。角丸半径と傾き、ボタンがピルか角丸四角か。
- **色** — 下のレシピで役割に割り当てる。
- **字** — 叫ぶ見出し（飾り書体・英字のみ）/ 丸い見出しとボタン / 太めで読みやすい本文、の 3 段。
- **生き物・小物** — マスコット 1 体（Frame で描ける単純な形）と、象徴物 2〜3 個（ボタンの絵文字、柄、看板の形）。
- **動き** — 弾む（Back イージング、押すと縮んで戻る）/ 漂う（Sine のゆっくりした揺れ）/ キビキビ（Quad で短く）。常時ループは 1 画面 1〜2 個まで。

参考画像があるときは `scripts/extract_palette.py` で色を拾い、「どの色が紙、どれがインク、どれが主役か」を画像の中での役割から決め直す。画像の色をそのまま UI に貼らない（写真の色は彩度と明度が中途半端で、UI の面にすると濁る）。

参考ゲームの名前が来たら、そのゲームの UI の「部品の作り」（縁の太さ、書体の性格、色数、CTA の置き方）を抽出して流用し、配色やモチーフはこちらのゲームのものにする。そのまま真似しない。

## 2. 配色レシピ

役割ごとに決める。spec の palette キーは括弧内。

- **インク (`ink`)** — 本文の文字と縁。純黒ではなく、モチーフの色相を混ぜた暗色（プラム、ココア、墨茶、深緑、暗い茄子色）。紺・スレートは避ける（lint が警告する）。
- **紙 (`paper`)** — パネルの面。純白ではなく、モチーフ寄りに色づいた明色（クリーム、生成り、ミントがかった白、羊皮紙）。`panel` はもう一段明るい面、`quiet` は入力欄などの控えめな面。
- **主役 (`primary`)** — CTA（PLAY 等）専用。画面で一番明度と彩度が高い色。他の用途に使い回さない（使うほど主役が埋もれる）。
- **キャンディ (`candies`)** — 4〜6 色。色相環で散らす（最低 50° 以上離す）。ドックのタイルや種類の違うボタンに割り当てる。名前はモチーフの言葉で付ける（`kingyo`, `ramune` など）とコードが読みやすい。
- **意味色** — `danger`（キャンセル・退出・削除）、`success`（完了・受け取り）。キャンディと被ってもよいが、同じ画面で意味と装飾を混同させない。
- **補助** — `muted`（補足文字。紙に対して 4.5:1 以上）、`disabled`（無効ボタンの面）、`dim`（モーダル背景の暗幕。黒ではなくモチーフ色の暗い洗い）。
- **パステル (`pastels`)** — 一覧の行ボタン用。キャンディを紙へ 75% 寄せた色。省略すると自動生成。インク文字が 7:1 以上で読めること。

文字色の規則（`kit:textOn` と board の規則は同一）:
- 明るい面（輝度 > 0.82）→ 暗い文字（`onLight`、通常はインク）。
- 明るめの面（> 0.65）で小さい文字（< 24 pt）→ 暗い文字。
- それ以外 → 白文字＋暗い縁取り（太さ = TextSize / 8.5、1.5〜4）。
この 1 つの規則で、どの色の面でも読めることを保証する。個別に文字色を決め始めると必ずどこかで読めなくなる。

## 3. 暗いモチーフ

深海・ホラー・宇宙・夜の街・洞窟などは暗い面が正解になりうる。そのとき「暗い紺の半透明パネル」にしないための手当て:

- **暗さに固有の色相を持たせる**: 深海は青緑（hue 180〜190）、ホラーは茄子紺〜血赤、宇宙は紫〜マゼンタ寄りの藍、夜の街は茄子色、洞窟は苔の暗緑。hue 205〜250 の低〜中彩度の暗色は lint が紺として弾く（195〜205 の暗い青緑は通る）。
- **明暗の役割を反転させる**: `paper` を暗く、`ink` を明るく（泡色・月光色）。縁取りとキャンディ上の文字は暗いままでないと読めないので、`outline` と `onLight` を別に暗色で指定する。
- **発光色のアクセント**: 主役とキャンディを蛍光寄りの高彩度にし、暗い面との明度差で光って見せる。UIStroke を 2 重（太く半透明＋細く不透明）にすると発光管らしくなる。
- **テクスチャで空白を埋める**: 泡（ドット、ゆっくり上昇）、星（小ドット＋たまに瞬き、点滅はしない）、霧（大きな半透明の丸）。
- **明るい面を 1 つ残す**: CTA や重要な札は明るい紙のまま（暗い画面に貼られたステッカー）にすると、暗い画面でも遊び心が残る。

## 4. 形・縁・質感

- **縁**: 3 px 前後のインク色の UIStroke（Border）。薄い縁（1 px、透明度 0.6 など）は AI っぽさの主因。パネルは 3〜4 px、ボタン 3 px、小さなバッジ 2〜3 px。
- **角丸**: 丸いモチーフで 16〜26 px、ピルは `UDim.new(1, 0)`。角張るモチーフは 4〜8 px。全部同じ半径にしない（パネル > ボタン > バッジ）。
- **下縁（lip）**: 面の下 6〜9 px を一段暗くして押し込める厚みを出す。押下中はずらして沈める。
- **艶（gloss）**: 色付きの面の上 1/3 に白 80% 透明の帯。飴・プラスチック・ガラスの素材なら付ける。紙・布・木なら付けない。
- **傾き**: CTA や見出しのステッカーを −2〜−4° 傾けると手貼り感が出る。全部傾けない（2〜3 要素まで）。
- **柄**: 縞（UIGradient のキーポイントで 10 本まで）、ドット（Frame の格子）、ドットや縞はパネルの背景や「近日公開」の札に。
- **影**: 真下へ 4〜6 px ずらしたインク色の板（透明度 0.7）を背面に置くとステッカーが浮く。ぼかし影は Roblox では高くつくので使わない。

## 5. 字

書体は `references/fonts.md` の実在一覧から選ぶ。組み合わせの型:

- **飾り見出し（display）**: モチーフの声。英字専用（LuckiestGuy、Bangers、Creepster、PermanentMarker、Fondamento、Michroma など）。日本語が入る文字列には使わない（`latinOnly`）。
- **見出し・ボタン（title / button）**: 丸く太い（FredokaOne）、硬く太い（DenkOne、Oswald、Sarpanch）、筆記風（Merriweather Bold）など。Bold 以上を要求する。
- **本文（body / strong）**: 読みやすさ優先（Nunito、BuilderSans、Montserrat、TitilliumWeb、Ubuntu）。Bold / Heavy。

日本語の UI では画面の文字の大半がシステムの日本語書体で描かれる。だから日本語の印象は「太さ」と「大きさ」と「縁取り」で作る。英字の飾り書体は CTA・モード名・数字などの短い英字に効かせる。

## 6. アイコン・マスコット・小物

- **絵文字アイコン**: 画像アセット無しで色付きアイコンが出る。系統を揃える（モチーフの物で統一。🏮🍎🐟 など）。TextSize の約 1.5 倍の箱に入れる（22 pt → 36 px、バッジは箱の 0.56 倍の TextSize）。
- **マスコット**: 丸い Frame の組み合わせ（体・腹・目・瞳・頬・くちばし/ヒレ/耳）で描く。部品は 8〜14 個。インクの縁取り、頬に半透明のピンク、目に白い点で急に生き物になる。ときどき瞬き、ゆっくり揺れる。置き場所はモーダルの角、ロード画面の進捗バーの上、空の一覧。
- **小物**: 看板の形（提灯、札、封蝋、ネオン板）、柄（縞・水玉・波）、背景の飾り（ViewportFrame で小さな 3D の情景を置くとモード選択が一気に「ゲームの箱絵」になる）。

## 7. 動き

- **押す**: 0.08 s で 94% に縮み、離すと Back イージングで 100% へ。下縁が沈む。
- **ホバー**: 104% に膨らむ、アイコンが少し回る。
- **出現**: 見出しは上から 10〜30 px 落ちながらポップ、カードは順番に 0.04 s ずつ遅らせる。
- **待機ループ**: CTA の後光の呼吸（1.8 s）、マスコットの揺れ（1.6 s）、背景の光線のスイング（3 s 以上）。
- reduced motion（`GuiService.ReducedMotionEnabled` かゲームの設定）ではループを止め、状態変化は即時に適用する。フラッシュ・高速点滅は使わない。

## 9. やりがちな「AI っぽさ」一覧

- 紺〜スレートの面に半透明、1 px の水色の縁、細い白文字。
- 全カード同寸・同色・同じ角丸、全部に同じ弱いドロップシャドウ。
- 主役の CTA が他のボタンと同じ見た目で、色だけ少し違う。
- 見出しが全部大文字の小さな英字ラベル（"SETTINGS"）で、字の階層が 1 段しかない。
- 色は 2 色（紺＋水色）で、モチーフの物が画面のどこにもいない。
- 意味の無いグラデーション（紫→青）を全面に掛ける。
- 空白を「余白」として残し、柄も小物も無い。
