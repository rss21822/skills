トーン: 静か・端正
7 軸: 素材 和紙・墨・朱肉・表具の布 / 形 角・筆の揺れ（UICorner は 0〜3 px）/ 色 墨の濃淡＋和紙＋朱（朱は印だけ）

モチーフを伏せたサブエージェントにスクリーンショットだけを見せたところ、次のように答えた。
「Japanese sumi-e ink painting on washi paper, like a hanging calligraphy scroll」
決め手に挙げたのは遠山・円相・款の下の朱印、色相は 3 と数えた。

## 画面への翻訳

| 場所 | 何にしたか |
|---|---|
| 背景 | 不透明な和紙（#F1EBDF）に淡い楮の繊維。元は 25 % 透過だったため、ゲーム世界の色が透けて色数が増えていた。そこで不透明にした |
| 主役（ホーム） | 画面左半分は余白として空ける。右に薄墨の遠山と円相の月を置く。中央には縦書きの款「七転八起」、その下にプレイの**朱の遊印**。款と印の組み合わせがそのまま落款になる |
| PLAY | 朱の角印。白抜きの「プレイ」、内側に彫りの細線、縁の欠けと朱肉の掠れがある。手押しの −1.2° と、開いた瞬間の押印演出付き |
| ナビ | 箱を描かず、墨書きの題字と筆の払いだけ。語の間には便箋の罫のような縦線。開いている頁の払いは濃く太くする |
| 頁（4 枚） | 横物の掛軸。八双・天地・一文字・風帯・軸と軸先・掛緒を付けた。題の前に一字の引首印（市・蔵・修・調）を押し、題の下には筆の界線を引く。背後は薄墨の暗幕で、月は掛軸の後ろに隠れる |
| 購入 | 墨印（黒い角印、掠れ付き）。閉じるはナビと同じ筆の払い |
| 設定 | ON は墨点の入った円相、OFF は薄墨の空の円 |
| 空の状態 | 持ち物は空の円相（無）、クエストは一筆の「一」と飛白 |
| 通貨 | 🪙 は Unicode 13 のため Roblox では豆腐になり、色も増える。これを墨の穴銭に置き換えた。他の処理が後から Text を書き換えても追従する |

「朱は落款だけ」は、1 画面で朱の塗りが 1 つになる形で守った。ホームは PLAY の印、頁を開いたときはその頁の引首印だけ。

配色は墨 #1E1A16 / 中墨 #4A433B / 薄墨 #8A8277、和紙 #F1EBDF / 本紙 #F8F4EA / 表具 #DDD4C2・#BDB39F・#A99F8C、朱 #BE3A26。
朱と白抜き文字のコントラストは 5.0:1、本文の墨と和紙は 14.6:1。

## 実装（`obby-rush/`）

- 実行時スキン（skill の方式 A）。共有の `src/shared/UITheme.luau` は編集していない。`MainMenu.luau` の変更は 2 行の呼び出しだけで、いずれも pcall で包んである。
  - 構築前に `Skin.apply(Theme)`：色表をその場で墨色に書き換え、panel / label / button を包む。
  - 構築後に `Skin.decorate(gui)`：主役画面の構図を組む。
  - スキンが無い、または失敗した場合は元の見た目で組み上がる。
- `src/client/ui/SumiSkin.luau` はアダプタと構図、`SumiParts.luau` は筆・円相・遠山・印・穴銭・掛軸の部品。
- `MotifSkinKit.luau` は skill 付属のキットをそのまま複製した。`MotifSpec.luau` は `skin/sumi-e.spec.json` から生成する。
- 名前・親子・コールバック・Visible と Active の判定・文言は変えていない。変えたのは見た目のプロパティ（色・書体・角・同じ Instance の大きさと位置）だけで、足したのはボタンではない `Motif*` 子要素だけ。
- 狭い画面への対応：
  - 頁を中心アンカーに変え、最小 320×230 にした。
  - ナビは幅に合わせて縮む（最大 560 px）。
  - 商品行は名前の下に値段を置く形にした。
  - 横持ちでは款を隠し、掛軸の天地を細くする。
  - タイトルは Roblox のトップバーの下へ移した（元はメニューボタンの下に潜っていた）。
- 動き：TweenService 経由で、reduced motion では即時に適用される。常時ループは霧の漂い 1 つだけ。

## 未検証・注意

- Studio は使っていない（共有中のため）。プレビューは実描画ではない。日本語は Noto Sans JP で近似しているが、Roblox は内蔵の CJK フォールバック書体で描く。
- Studio で要確認の点：
  - UIStroke に付けた UIGradient（円相のかすれ）の見え方
  - 書体の太さ
  - `studio_ui_audit.luau` による実測監査
- `Skin.apply` は共有テーマを書き換える。このメニューを開いた後に同じクライアントで作られる他の画面も、墨の見た目になる（意図どおり）。
