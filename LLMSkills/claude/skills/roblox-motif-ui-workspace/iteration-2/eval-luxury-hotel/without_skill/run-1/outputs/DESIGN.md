# Obby Rush: "The Grand Hotel" UI の設計メモ

依頼は、舞台を高級ホテルにすること（黒い大理石、金の装飾、シャンデリアのあるロビー）、UIを上品で大人っぽくすること、可愛さやポップさは入れないこと、そしてテストを壊さないことでした。
このプロジェクトに入っているのはメインメニューだけです。3Dのワールドは含まれていません。そこでメニュー自体をホテルのロビーとして組み立てました。

## モチーフをUIにどう置き換えたか

| ホテルの要素 | UIでの形 |
|---|---|
| ネロ・マルキーナ（黒地に白い筋の大理石） | パネルと背景は黒の斜めグラデーションで磨いた石の艶を出す。白い筋は折れ線と枝分かれで描き、透明度0.9以上に抑える（`Theme.marble` / `LobbyBackdrop.veins`） |
| 金の装飾（アールデコ） | 1pxの金ヘアライン、中央に菱形を置いた罫線（`Theme.rule`）、段状の柱頭を持つ左右の付柱、カードの二重枠と四隅の菱形（`Theme.inlay`） |
| シャンデリアのロビー | 金の二重罫の下に、クリスタルの房を並べたシャンデリアを吊るす。前後2列の房、ずらして配置したビーズ、ドーム形に並んだ雫。全体を暖色の光で包む（16枚の円をほぼ透明に重ねてバンディングを抑えた） |
| ホテルの社名ヘッダー | TopBar は箱をやめて中央寄せにした。金箔グラデーションの字間を空けた「OBBY RUSH」、その下に「THE GRAND HOTEL」、左右に金罫。四隅は Roblox の標準ボタン用に空けてある（旧版はタイトルが左上のボタンと重なっていた） |
| 館内サイン（和英併記） | NavBar はロビーの案内板にした。英語は字間を空けた金の小文字大文字、日本語は下に置く。BOUTIQUE=ショップ、CLOAKROOM=持ち物、CONCIERGE=クエスト、PREFERENCES=設定。開いている部屋には金の下線を付ける |
| チェックイン | PLAY は画面で唯一のベタ金ボタン。上に「CHECK IN」、主表記は「プレイ」のまま |
| レストランのメニューカード | ショップは品名、点線リーダー、金の価格、控えめな金枠の「購入」を並べる。区切りは箱ではなく罫線 |
| 真鍮とオニキス | 設定は和英併記の行に、金とオニキスのスイッチを組み合わせた。状態は「ON」を金、「OFF」を灰褐色で表示 |

意図して入れなかったものは、絵文字（🪙 は金箔コインの図形に置き換えた）、角丸の大きいピル形、彩度の高い青、跳ねるアニメーションです。角はすべて2px、動きは0.14秒の色の遷移だけにしました。動きを減らす設定（ReducedMotion）がオンのときは即時に切り替わります。

既存のキー（background / panel / panelLight / accent / text / subtext / danger / success）はすべて残しているので、ほかの画面もそのまま動きます。
コントラスト比（WCAG）は、パネル上のアイボリーが15.6:1、灰褐色が6.5:1、金が8.2:1です。金ボタン上のインクは8.0:1で、グラデーションの一番暗い下端でも4.2:1あります。

## 書体

- `Enum.Font.Bodoni`: ラテン文字全般（ワードマーク、数字、ON/OFF）。ウェイトは1種類なので、序列はサイズ、大文字、金色で付けた。
- `Enum.Font.JosefinSans`: アールデコ系の幾何学サンセリフ。字間を空けた英語キャプション（`Theme.track` は Roblox に letter-spacing が無いため空白で代用している。ASCIIのキャプション専用）。
- 日本語は Roblox の CJK ゴシック（Regular）にフォールバックする。ラテン文字はセリフ、日本語はゴシックという組み合わせは、実際のホテルの和英サインと同じ作りになる。

## 契約と互換性

テストで固定されているインスタンス名、コールバック、ページ切替、タッチ領域48px以上はすべて維持しました。`tests/` は変更していません（sha256 で確認済み）。
Theme の API は旧シグネチャを保っています（`panel(parent, name, size, position)`、`button(..., {primary, danger, size, order, textSize})` など）。

表示の変わった点は次のとおりです。

- `CoinLabel.Text` は「🪙 1250」から「1,250」になった（テストは両方の書式を許容している）。外部スクリプトが旧書式で書き込んでも、数字に正規化し、コイン図形の位置も追従させる。
- トグルの `Text` は RichText になった（例: `音楽　<font color="#9E9689">OFF</font>`）。
- `MainMenu.open(gui, nil)` で全ページを閉じられるようにした。
- `MainMenu.layout` を追加した。ビューポートの高さが560px未満（スマホ横持ち）のときは、カードをヘッダーと案内板の間に収め、見出しを1行にする。

## 検証

- `lune run tests/test_main_menu.luau` は29件すべて合格しました。
- Studio は使っていません（共有環境のため）。見た目は `preview-tools/` で確認しました。仕組みは次のとおりです。
  1. テストと同じ mock で `MainMenu.build` を実行し、GUIツリーをJSONに書き出す。
  2. 自作の Roblox GUI レイアウト再現器（UDim2 / AnchorPoint / UIListLayout / UIPadding / UIAspectRatioConstraint / UICorner / UIStroke / UIGradient / RichText）でHTMLに描画する。
  3. ヘッドレス Chrome でPNGを撮る。
- プレビューにある画面は、ロビー、ショップ、設定、持ち物、ホバー、スマホ横持ち2画面、比較用の変更前2画面です（`preview.html`、`preview_*.png`、`preview_contact_sheet.png`）。

### 注意点

- プレビューは近似です。Bodoni は Accanthis ADF Std で代用しています（Roblox の Bodoni の実体と判断したもの）。日本語は Noto Sans JP で描いています。実機ではグリフ幅や行送りが数pxずれる可能性があります。コイン図形と点線リーダーの位置は文字幅の推定に基づいて決めています。
- 装飾のインスタンス数は約650で、変更前は86でした。ほとんどはシャンデリアです。静止したメニューなので問題にならない想定ですが、低スペック端末で気になる場合は、シャンデリアを1枚の画像（ImageLabel）に焼き込めば数十個まで減らせます。
- 3Dの舞台はこのプロジェクトに含まれていないので作っていません。ワールド側を合わせる場合の目安は次のとおりです。
  - 床と壁: Marble、Color #141416、白い筋のテクスチャ
  - 金の縁取り: Foil または Metal、Color #C9A55E
  - シャンデリア: PointLight、Color #F6D698、Brightness は低め
