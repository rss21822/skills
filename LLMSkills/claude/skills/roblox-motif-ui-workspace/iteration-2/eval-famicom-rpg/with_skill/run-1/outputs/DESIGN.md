## 翻訳表

| モチーフの要素 | 実装 |
|---|---|
| 黒い画面 | `Background` を不透明の黒 (#000000) に。元は紺の 25% 透過 |
| 白い枠のウィンドウ | 上下左右 4 本の白いバー (4px) で枠を描き、各角を 1 ドット欠く（NES のウィンドウタイルの丸角）。UICorner は 0、元の水色 1px の UIStroke は無効化 |
| ウィンドウは入れ子にしない | ウィンドウ内のパネル（商品の行）は枠なしの「行」になる |
| ドラクエのウィンドウ見出し | ページ見出し（おみせ等）を上枠の線の上に黒地で乗せ、線を切る |
| ▶ のカーソル | Frame 4 本（高さ 7-5-3-1 ドット）で描いたドットの ▶。フォントに頼らないので絵文字化しない。ドットの大きさは隣の文字のピクセルに合わせる（START 32px なら 4px） |
| カーソルの振る舞い | 画面に点滅するカーソルは常に 1 つ。ホバー/選択/タップした項目へ移る。ページを開くとそのウィンドウの最初のコマンドへ入り、開いたコマンド（▶おみせ）には点滅しない「記憶カーソル」が残る。押下中は白黒反転 |
| ドット文字 | 英字・数字（START、OBBY RUSH、G 1250、300G）は PressStart2P を 8 の倍数のサイズで。日本語は Roblox にドット書体が無いため RobotoMono + システム CJK の Heavy/Bold |
| ファミコンの文言 | かなだけ・文節で空白（どうぐ / せってい / とじる / かう / まだ なにも もっていない。）。お金は「G」（元の 🪙 は Unicode 13 で Roblox では □ になる） |
| タイトル画面 | ドット書体のロゴ + レンガ色と暗赤の 1・2 ドットずらした影、足踏みする走者の小さな情景、中央に「▶START」ウィンドウ |
| 主役は 1 つ | 金色の文字は START だけ（テストで検証）。ほかは白。ショップの「かう」だけは元コードの primary 指定を尊重して金 |

パレットは NES の実パレット値: 黒 #000000 / 白 #FCFCFC / 金 #F8B800 / 赤 #F83800 / 緑 #58D854 /
灰 #BCBCBC・#7C7C7C、ドット絵に #F8D878 #0058F8 #00A800 #E45C10 #A81000。
spec は `obby-rush/design/famicom-rpg.skin.json`（lint 0 error。警告 2 件は意図どおり:
純黒は「黒い画面」の指定そのもの、無効状態は面を塗らず灰色の文字 5.0:1 で表すため）。

## 実装方式と変更範囲

- **実行時スキン（方式 A）**: `src/client/ui/FamicomSkin.luau` が `UITheme.colors` をその場で書き換え、
  `Theme.corner / stroke / panel / label / button` を包む。UITheme を使う他の画面も同じ見た目になる。`UITheme.luau` 自体は無変更。
- **主役画面**: `Skin.decorateMainMenu(gui)` がメインメニューをタイトル画面に配置（ロゴ、情景、START、コマンドウィンドウ、
  ページの大きさと位置、画面サイズ別のレイアウト）。途中で失敗したら行った変更を全部巻き戻し、元の見た目で表示する。
- **MainMenu.luau の変更は最小**: スキンを pcall で読み、文言を `Skin.copy` から取る（無ければ元の日本語）、最後に decorate を呼ぶだけ。
  スキンのフォルダが無くても元どおり動く（テスト済み）。
- **名前の契約は不変**: 既存 Instance の Name・親子関係・属性・コールバック・有効判定は変えていない。追加した子は全て `Motif*`。
  スキン有り/無しで「Motif 以外の全 Instance のパス+クラス」が完全一致することをテストで確認。
- トップバー: `IgnoreGuiInset` の画面で、元はタイトルとコインが Roblox のメニューボタンの下 (y=16) に潜っていた。
  スキンでは y=70 以降に置く。
- 画面サイズ: デスクトップ（情景あり）、横持ちスマホ（ロゴと G を 1 行、情景なし、ページは縦いっぱい）、
  縦持ち（コマンドを 2×2 のグリッドに: `UIListLayout.Wraps`）。
- reduced motion: カーソルは点いたまま、走者は静止。ループは 1 画面 1 本（0.5 秒刻み）、画面を消すと止まる。

  ウィンドウ/行/見出しの形、文言と書体、金は START だけ、カーソルの移動・記憶・点滅・押下反転・無効時の灰色、

- `lune run tools/compile_all.luau` → 全 .luau コンパイル OK

## 制約・未検証

- **Studio 実機では未確認**（共有中のため指示どおり起動していない）。プレビューは Web の代替書体
  （Press Start 2P / Roboto Mono / Noto Sans JP）で描いた近似。文字幅は推定値で、実機では TextBounds を使ってカーソル位置を補正する。
- **日本語はドット文字にならない**: Roblox 内蔵書体に日本語のドット書体は無く、システムの CJK 書体へ落ちる。
  かなのみの文言・Heavy・英数字のドット書体で寄せたが、滑らかな日本語とドットの英数字の混在は残る（盲検でも指摘）。
- 既存の挙動で気付いた点（変えていない）: ページの Frame が `Active = false` のため、開いたウィンドウの空き部分をクリックすると
  背後の START やコマンドに届く。`page.Active = true` で防げるが、入力の振る舞いの変更なので見送り。
