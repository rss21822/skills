# 品質の基準（「超一流」の定義）とモード別チェックリスト

数値は SpinOut anim-elite（2026-09-25、R15 ブロック体、氷上スケート）での実績値。別のゲームでは出発点として使い、
自分の体・カメラ距離・速度域で測り直す。「推定」と書いたものは実測していない。

## 目次

1. 12 の原則（何を見て良し悪しを決めるか）
2. 合否の数値
3. モード別チェックリスト（移動 / 旋回 / 空中と着地 / 攻撃・スピン / 被弾・よろけ / 停止 / 待機・構え / 要素 / エモート）
4. ゲームカメラ距離で読めるか

## 1. 原則

1. **接地が最優先**: 足が床に沈む・浮く・踏んだ足が滑るのは、どんな美しいポーズより目立つ。まず全モードで接地を数値で閉じる。
2. **重心と支持**: 体重がどの足に乗っているかを見せる。荷重側の膝が深く、非荷重側が軽い。両足同じ深さは静止画に見える。
3. **予備動作 → 本動作 → フォロースルー**: 逆方向へ溜める（スピンなら胸を逆へ巻く）、本動作は速く締める、終わりは行き過ぎて戻る。
4. **重なりと遅れ**: 頭・腕・胸は体幹より遅れて動き、遅れて止まる（ばね）。全関節が同時に止まるとロボットに見える。
5. **弧**: 手足の先は直線でなく弧を描く。IK で位置を決めるときも、関節角の補間で弧を残す。
6. **非対称**: 左右同じ・周期が見える動きは機械的。周期を 2 つ重ねる（例: 体重移動 6.4 s と呼吸 3.2 s と目線の遅い周期）、左右で振幅と位相をずらす。
7. **物理と一致**: 曲がれば向心加速度の分だけ内へ（atan(a/g)、見栄えのため 1.0〜1.35 倍に誇張）、加速で前、減速で後ろ。
   速度から計算するので、どの体・どの入力でも自然に合う。
8. **視線が導く**: 頭は曲がる先を先に見る（角速度に比例して先行）。体が傾いても目線は水平寄りに保つ（付け足した傾きの約 55% を首で戻す）。
9. **シルエット**: ゲームカメラ（中距離・斜め上）から形が読めること。ブロック体は脚幅 1 stud あるので、交差や開脚は実際の人体より大きな角度が要る。
10. **連続**: 1 フレームの最大回転を予算内に（遷移 360°/s ≒ 60 fps で 6°/frame）。補正の出し入れも同じ予算で。衝撃（被弾・着地・スピンの開始）だけは速い応答を許す。
11. **作者の動きを尊重**: 購入済み・既存の track に重ねるときは位相・速度・並進を止めない。足すのは差分だけ。
12. **全員に同じ品質**: 自機・NPC・他プレイヤー、縮尺違い・Rthro で同じ接地。自機だけ良いのは失敗。

## 2. 合否の数値（出荷の目安）

- 接地: 地上フレームで低い方の足の最下点 ≥ −0.02 stud（計測の基準ずれ −0.002 程度は許容）。意図した持ち上げ以外で > +0.05 のフレームは ~0。
- 跳び: 通常の遷移で 1 フレームの最大回転 ≤ 6°（60 fps）。overlay の入りで補正が加わる区間は ≤ 9°、ただし原因を説明できること。
- 着地: 強い着地（落下 −60〜−72 stud/s）でも沈みは 1 フレーム ±0.15 以内（Humanoid の圧縮のため 0 にはできない）。弱い着地は ±0.03。
- 二次運動: 定常旋回の傾き = atan(gain·v·ω/g) ±1°、上限で頭打ち、NaN・発散なし（30 / 60 / 144 fps で同じ）。
- コンソール: client / server とも自分の変更由来のエラー・警告 0。
- 負荷: 12 体以上で毎フレームの Instance 生成なし、属性書き込みは値が変わったときだけ。

## 3. モード別チェックリスト（anim-elite の実装値つき）

### 移動（走り・滑走）

- 購入済み／既存の走り track は体格差で足が沈み・浮く（実測: Run −0.24〜+0.11、Glide −0.42〜−0.11、Lean −0.50〜+0.08）。
  → 地上では低い方の足を「立ったときの足の高さ」へ Root の縦移動だけで合わせる（関節は回さない）。離地で重みを 0 へ、着地で時定数 60 ms で 1 へ。
- 加速で上体前傾（最大 9°）、減速で後傾（最大 8°）。Waist だけ、脚には触れない。
- 速度帯でスタイルを変えるなら、切替は gather（両足を揃えた中間姿勢）を経由し、360°/s の予算で。

### 旋回（片足滑走・クロスオーバー）

- 旋回の入力が続いて 0.6 s 経ってから overlay へ（すぐ入ると細かい舵で揺れる）。明示のクロスオーバー指示なら 0.25 s。
- 支持脚（内側）: 深いエッジの膝。速度で 46〜68°、外脚が後ろへ押すたびに荷重で少し沈み、前へ運ぶと戻る。刃は骨盤より円の外、重心は刃の内。
- 外脚: **再生中の track の関節そのもの**（位相・速度を保つ）に、前へ振れる区間だけ腿を内へ寄せる（股関節の前後角 0→60° で 0→28°。
  28° は脚幅 1 stud・脚長 2.2 stud で外刃が内刃の前を越える角度 atan(1.1/2)）、膝を抱え上げ（屈曲 +12°）、腿を追加で 8° 前へ。
- 内刃を固定すると外脚の押しが床へ沈む → 押しの間は脚を縮めて床の上を滑らせ（±0.06 の緩和帯で二次曲線）、体を傾けて浮いた分は IK で伸ばして届かせる（soft IK 5%）。
- 骨盤は外脚を追って 5° 回り、胸は逆へ回して肩を静かに（カウンター）。外腕は外脚と逆位相（股関節角 × 0.35、最大 18°）。
- 体全体の内傾は二次運動（向心加速度）から。作者の傾きと二重にしない。

### 空中と着地

- 空中: 床を raycast、1 物理ステップ先を予測して足を床より下へ入れない（上げるだけ）。
- 着地の吸収は接地の約 30 ms 前から始める（遅れると膝が衝撃に負けて見える）。衝撃の強さ = clamp(−落下速度/55, 0.35, 1) で膝の深さを変える。ピーク約 0.09 s、0.34 s 以上は着地の姿勢を残す。
- 回転ジャンプ（Axel など）: 回転中は脚を揃え前腕を胸の前へ畳む、最後の 1/4 回転で腕と遊脚を開き始める、片足の膝で受けて着地。
- 強い着地の 1 フレーム ±0.15 は物理の圧縮が原因で残る（描画は物理の前の root で計算するため）。

### 攻撃・スピン

- 3 段で作る: 予備動作（低く沈み、腕を広げ、胸を逆へ巻く。SpinOut 0.12 s）→ 本動作（締める。支持脚を伸ばし、遊脚をパッセ、前腕を胸骨の前で水平に畳む）→ 立て直し（腕をすぐ開いて止め、頭と胸が遅れて揺れ戻る、0.8 s、0.45 s から通常へ）。
- 体ごと回る動きは支持足を回転軸の真下へ寄せる（足が円を描かない）。
- 入りは速く（0.06 s）、予備動作の時間を食わない。
- 剣・拳の攻撃も同じ構造: 溜め（逆へ引く）→ 振り（速い、弧）→ フォロースルー（行き過ぎて戻る、重い武器ほど長い）。ヒットストップを入れるなら描画の時計だけ止め、物理と入力は止めない（推定、SpinOut では未実装）。

### 被弾・よろけ

- 最初の反動で上体が弾かれ、捕まり足の刻みが 5 Hz から 2.5 Hz へ落ちながら減衰（残り 35%）。左右の足で振幅と位相をずらし、腕は非対称に振り回して釣り合いを探す。
- 入りは速く（0.07 s）。二次運動は弱める（頭の先行 0.35 倍）。

### 停止

- 止め方を開始時の速度で決め、止まるまで変えない（途中で切り替えると跳ぶ）: 高速は横向きのホッケーストップ（体を 78° 回し、後ろへ倒れ、前脚に荷重、刃のびびり 9 Hz 減衰）、中速は T ストップ、低速はハの字。

### 待機・構え

- 待機: 足を少し外へ開いて膝を緩め、6.4 s で体重を左右へ（荷重側の膝が少し深い）、3.2 s の呼吸、二つの遅い周期を重ねた目線。周期が見えないこと。
- 構え（スタート前）: 待機 → 構えへ沈み、開始の直前から腕を後ろへ振り膝を溜める（予備動作）。開始直後の数フレーム（入力がまだ Idle）も構えを保ち、発進の動きへ直接渡す（一度立ち上がって沈み直す段差を出さない）。

### 要素（フィギュア系の見せ技）

- 形を大きく: SpreadEagle は体の向き 80°、膝は柔らかく −8°。Spiral は上体 + 腰の前傾 60° 超、遊脚は水平より上（脚の向きの Y 成分 0.25〜0.5）、遊足は 2.8〜3.4 stud 上。
- 走り → gather → 要素 → 走り を 360°/s の予算で。遊脚を上げる要素から両足の要素へ移るときは、遊足を段階的に接地させる（一気に足首を解くと 1 フレームで跳ぶ）。

### エモート・全身の上位 track

- Action2 以上で全身を持つ track が再生中は、ポーズレイヤーの overlay と二次運動を即座に外す（ばねも 0 から）。ただし接地（縦移動だけ）は掛けてよい。
- 有料エモート用に確保した動きは、勝手に通常操作へ割り当てない（依頼の範囲を確認）。

## 4. ゲームカメラで読めるか

- 実際のゲームカメラの距離と角度で撮る（クローズアップだけで判断しない）。ブロック体は細部が潰れるので、角度を大きく、時間を少し長く。
- 1 秒未満の動き（着地、スピンの入り）は TimeScale を下げて撮り、形の順番（溜め → 締め → 開き）が読めるかを見る。
- 動画が撮れないなら、同じ時刻の複数フレームを並べて比較する。
