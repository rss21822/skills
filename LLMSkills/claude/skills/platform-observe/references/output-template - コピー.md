カテゴリ枠: <採用したアンカー。例: 公式ジャンル分類＋<アワード名><年>受賞区分を軸に実勢補正>

## シリーズ実行時の追加ファイル

`observe-<platform>-series-notes.md`:

```markdown
# Observeシリーズ変遷メモ — <プラットフォーム> <開始年>〜<終了年>

## カテゴリの新設・消滅
- <年>: 「<カテゴリ>」新設（契機: <作品/事件>）
- <年>: 「<カテゴリ>」消滅・統合（理由）

## カテゴリ別王者交代年表
- <カテゴリ>: <作品A>（<年>〜）→ <作品B>（<年>〜）→ ...

## 期間全体の大きな流路変化
- <年>: <アルゴ変更・大事件と影響1行>
```

## 記載スタイル注意

- 作品エントリは1〜2行厳守。詳細解説はしない（Observeは観察であり解説ではない）
- 潮流ノートに「次に何を作るべきか」を書かない（それはIdeateの領分）
- 数値は指標名を必ず併記（「500万」ではなく「ピーク500万CCU」「累計500万DL」）
- 同一作品が複数カテゴリ該当なら主カテゴリに置き、他方には「（重複掲載）」で参照
