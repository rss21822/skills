# プラットフォーム別アンカー集

Observe実行時、対象プラットフォームの節を読み、カテゴリ枠・規模指標・データソースを
ここから確定する。記載のないプラットフォームは本ファイルの「共通原則」を適用し、
採用したアンカーを出力冒頭に明記すること。

## 共通原則

1. カテゴリ枠の優先順: 公式ジャンル分類 > 公式アワード区分 > 大手メディア年間総括 >
   コミュニティ通念（wiki等）。採用したものを出力に明記
2. 規模指標はプラットフォーム標準を使う。異種指標の直接比較をしない
3. 年代が古くWeb資料が薄い場合: Wayback Machine（当時の公式チャート・ストアページの
   スナップショット）、当時のフォーラム・年鑑・GDC/CEDEC講演資料
4. どの年でも「その年に実際に遊ばれていたか」で判定（発売年ではなく人気の年）

## Roblox

- **標準指標**: 同時接続（CCU: ピーク/平常）、累計visits、favorites、like率
- **カテゴリ枠**: 公式ジャンル分類（2024年改定版: Action / Adventure / Horror /
  Obby & Platformer / Party & Casual / Puzzle / Roleplay & Avatar Sim / RPG /
  Shooter / Simulation / Sports & Racing / Strategy / Survival / Tycoon 等）。
  実勢補正カテゴリ例: Steal系、デスゲーム/大人数淘汰、異変探し、バトルグラウンド
- **アワードアンカー**: Roblox Innovation Awards（RIA, 2022〜。年次カテゴリ別受賞は
  カテゴリ枠の最有力アンカー）。それ以前はBloxy Awards（〜2021）
- **データソース**: RoMonitor Stats（CCU履歴）、Rolimon's（ゲーム統計）、
  Statista（歴代visits）、公式Charts、DevForum、gamebiz/GameBusiness.jp（日本語報道）
- **時代注意**: 2020年COVID流入、2025年GaG/SaBの記録期、2025年末アルゴ変更
  （クリック→定着重視）、2026年年齢レジーム分化。これらを跨ぐ比較は文脈注記

## Steam

- **標準指標**: 同時接続（SteamDB CCU）、売上（公式Best of Year: Platinum〜Bronze階級）、
  レビュー数・評価率
- **カテゴリ枠**: Steamタグ上位＋公式Best of Yearのカテゴリ、The Steam Awards区分
- **アワードアンカー**: The Steam Awards（2016〜）、公式年間ベストセラー/最多同時接続
  リスト（公式発表・階級制）
- **データソース**: SteamDB、Steam250、SteamSpy（旧年代）、公式年末発表
- **時代注意**: Early Access文化（2013〜）、バトロワ期（2017〜18）、
  ソーシャル系サバイバル波（2024〜）、中国市場比率の変化

## Fortnite（UEFN / Creative）

- **標準指標**: アイランド同時接続・プレイ時間（公式Discover / fortnite.gg）
- **カテゴリ枠**: 公式Discoverのジャンル行（Battle Royale本体と分けて、
  Creative/UEFNアイランドを対象にするか冒頭で宣言）
- **アンカー**: Epic公式ブログ・エコシステム収益レポート、fortnite.gg統計
- **時代注意**: 2018 Creative開始 / 2023.3 UEFN＋Creator Economy 2.0開始
  （それ以前の「ヒット島」は指標が薄い）。ブランド公式島とUGC島を区別

## VRChat

- **標準指標**: ワールド人気（訪問数・お気に入り数）、同時インスタンス状況。
  「ゲーム」より「ワールド/イベント」単位
- **カテゴリ枠**: ゲームワールド / 交流・Chill / イベント（DJ・ライブ）/
  ホラー / 脱出・謎解き / ミニゲーム定番（Murder 4等）
- **アンカー**: 公式ピックアップ、VRChat内トレンド、コミュニティ年間総括
  （日本語圏はバーチャルライフマガジン等）
- **時代注意**: Quest対応可否が人気を左右。日本コミュニティ比率が高く
  日本語ソースが有効

## モバイル（iOS / Android）

- **標準指標**: DL数・売上（Sensor Tower / AppMagic / data.ai系の推計）、
  ストアランキング滞在
- **カテゴリ枠**: ストア公式カテゴリ＋実勢（ハイパーカジュアル/ハイブリッドカジュアル/
  ミッドコア/パズル/4X/放置 等）
- **アンカー**: App Store Awards / Google Play Best of（年次）、
  各調査会社の年間ランキング記事
- **時代注意**: ハイパーカジュアル最盛期（2018〜21）→IDFA変更（2021）→
  ハイブリッド化。日本市場と欧米市場でチャートが大きく異なるため地域を宣言

## コンソール / マルチプラットフォーム全体

- **標準指標**: 販売本数・MAU（公表値）、受賞歴
- **アンカー**: The Game Awards（GOTY含む年次区分）、各社決算・年間ランキング、
  ファミ通年間販売（日本）
- **用途注意**: 本スキルの主用途はUGCプラットフォーム観察。コンソール全体を扱う場合は
  「プラットフォーム」ではなく「市場」観察になる旨を冒頭注記
