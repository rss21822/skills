# Platform Observe — 年次プラットフォーム観察スキル

指定プラットフォーム×指定期間の「カテゴリ別ヒット作リスト＋潮流ノート＋横断サマリ」を
生成する。ゲーム史をメタナラティブ（系譜）として読むための一次観察資料を作る。

## 入力

- **プラットフォーム**（必須）: Roblox / Steam / Fortnite(UEFN・Creative) / VRChat /
  モバイル(iOS・Android) / コンソール / その他。未指定なら会話文脈から推定し、確認する
- **期間**: 年（例: 2020）または半期（例: 2026上半期）。未指定なら直近12ヶ月
- **シリーズ指定**（任意）: 「2018〜2025を各年」等。1期間=1ファイルで連続生成

## ワークフロー

### 1. アンカー確定（Web調査必須）
その期間のカテゴリ枠と規模指標の「公式アンカー」を特定する。
`references/platform-anchors.md` を読み、対象プラットフォームの節に従うこと。
- 公式ジャンル分類・公式アワード（例: RobloxならRIA）・公式年間ランキングを優先
- アンカーが存在しない年代は、当時の主要メディアの年間総括記事で代替し、その旨明記

### 2. カテゴリ枠確定
- 公式分類を軸に、実勢（実際のヒット分布）で補正した8〜14カテゴリを設定
- **シリーズ実行時はカテゴリ互換性を最優先**: 前後の年のファイルと同名カテゴリを
  使い、年ごとの差分（新設・消滅カテゴリ）は明示的に「新設」「消滅」と記す。
  これにより複数年ファイルのdiffが潮流の変遷として読めるようになる

### 3. カテゴリ別収集（各カテゴリ最低3本）
各作品につき1〜2行で記載:
- 作品名（ローンチ時期）＋確度タグ＋ヒット規模根拠（CCU/DL/売上/visits等、
  そのプラットフォームの標準指標で）＋一言コア
- 確度タグ規律: **[確]**=出典URLあり / **[要確認]**=言及はあるが規模未検証 /
  **[知]**=一般知識・通説（裏取り推奨と明記）
- （継続）タグ: 対象期間より前のローンチだが期間内も上位の作品
- **アナクロ検査**: その期間に存在しなかった作品・機能を混入させない。
  ローンチ年が期間より後の作品を発見したら即除外
- **生存者バイアス注意**: 当時話題になったが後に消えた作品も、観測できれば
  積極的に収録する（後年の系譜分析・コンプス構築の貴重な母集団になる）

### 4. 潮流ノート（カテゴリごと1〜2行）
そのカテゴリで大群がどう動いたかの解釈を圧縮記述:
- 例:「記録製造カテゴリ。○○が標準装備化」「△△記号の誕生」「遠征と籠城へ分化開始」
- 事実（リスト）と解釈（ノート）を混ぜない。解釈はノート欄のみ

### 5. 横断サマリ（大群分布の読み）
全カテゴリを俯瞰し、以下の5分類で1行ずつ:
- **記録製造帯**: その期間の記録級ヒットを出したカテゴリ
- **質的中心帯**: 賞・評価・定着が集中したカテゴリ
- **成長株帯**: 規模は中位だが上昇・分化中のカテゴリ
- **飽和・寡占帯**: 王者固定・新規参入が報われないカテゴリ
- **空白確認**: ヒット不在のまま残っている領域

### 6. 冒頭にプラットフォーム状況、末尾に出典リスト
- 冒頭: その期間のプラットフォーム全体状況を1段落（規模・大事件・
  アルゴリズムやポリシー変更等、大群の流路を変えた要因）
- 末尾: 出典URL一覧。[確]項目はすべてここに対応する出典を持つこと

## 出力

- ファイル名: `observe-<platform>-<period>.md`（例: `observe-roblox-2020.md`,
  `observe-steam-2024.md`, `observe-roblox-2026H1.md`）
- 形式: `references/output-template.md` の構造を厳守。テンプレートから逸脱する場合は
  理由を冒頭に注記
- シリーズ実行時: 1期間=1ファイル。全ファイル生成後、簡易な変遷メモ
  （カテゴリ新設・消滅・王者交代の年表）を別ファイル
  `observe-<platform>-series-notes.md` として添付

## 規律（全実行で遵守）

1. **推測禁止・出典必須**: 数値・年代・受賞歴は出典URLとセットでのみ[確]表記。
   取れなければ[要確認]/[知]で正直に
2. **その時点の視点で書く**: 「後にヒットする」等の後知恵は潮流ノートでのみ許可し、
   リスト本体は当時の観測事実に徹する
3. **ヒットの単位はプラットフォーム標準に従う**（anchors参照）:
   RobloxはCCU/visits、SteamはCCU/売上、モバイルはDL/売上、VRChatはワールド人気。
   異プラットフォーム比較を安易にしない
4. **量より確度**: 3本×正確 ＞ 10本×曖昧。カテゴリで3本集まらない場合は
   「当該期間ヒット薄」とそれ自体を観測結果として記す
5. 古い年代（Web資料が薄い時期）は Wayback Machine・当時のフォーラム・
   年鑑記事を使い、それでも欠ける場合は[知]主体になる旨を冒頭に明記

## 他システムとの連携

- 本スキルの出力は Cultural Currents 系譜分析（genealogy-analyst）の一次資料、
  および定量評価（roblox-quant-eval / comps-builder）の母集団の当たりとして使える
- Interpret（シグナル判定）・Ideate（企画発想）は本スキルの守備範囲外。
  求められたら該当スキル/エージェントへ引き継ぐ
