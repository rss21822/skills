## 1. 読み方（7 軸）と言い換えテスト

モチーフを一文の雰囲気で受け取らず、画面の部品に落ちる言葉へ分解する。各軸 1〜2 語で十分。

- **トーン** — 可愛い / 元気 / かっこいい / 怖い / 上品 / 懐かしい / 静か。混ざってよい（「怖いけど子供向け」「上品で少し遊び心」）。次節の出発点を選ぶ。
- **素材** — そのモチーフの世界で「看板」や「札」は何でできているか。紙のステッカー / 飴細工 / 木札 / 和紙 / 羊皮紙と封蝋 / 真鍮と大理石 / 錆びた鉄板 / ネオン管 / 布のワッペン / 石板 / ブラウン管のドット。パネルの面、縁の色と太さ、艶の有無、影の出し方が決まる。
- **形** — 丸い（飴・泡・ぬいぐるみ）/ 角が立つ（金属・結晶・機械）/ 手描きで揺れる / 切り欠き（チケット・札）/ ドットの階段 / アーチ。
- **色** — 4 節のレシピで役割に割り当てる。色数もモチーフから（墨と朱だけ、ゲーム機の 4 色、キャンディ 6 色）。
- **字** — 声になる見出し / 見出し・ボタン / 本文、の 3 段。
- **物** — マスコット、象徴物、紋章、看板の形。生き物がいないモチーフで無理にマスコットを作らない。
- **動き** — 弾む / 漂う / キビキビ / 滲む / ゆっくり明滅 / コマ送り。

参考画像があるときは、画像を見て形・質感・字・構図を言葉にし、`scripts/extract_palette.py` の色を「どれが紙、どれがインク、どれが主役か」画像の中での役割から決め直す。写真の色をそのまま UI の面に貼らない（濁る）。

参考ゲームの名前が来たら、そのゲームの UI の「部品の作り」（縁の太さ、書体の性格、色数、CTA の置き方）を抽出して流用し、配色やモチーフはこちらのゲームのものにする。そのまま真似しない。

**言い換えテスト**: ブリーフと board を書いたら、モチーフ名を伏せて「この画面は何の世界か」を自問する。答えがモチーフ以外でも通る（「ポップなゲーム」「暗いゲーム」）なら、世界の中の UI（3 節）が足りない。逆にモチーフの物を並べただけで部品の作りが汎用なら、素材（6 節）が足りない。

ユーザーの明示指定（色、書体、「可愛くしない」「紺と白で」「マスコット無し」）は、この文書のどのレシピより優先する。

## 2. トーン別の出発点

トーンが決めるのは既定値だけ。ここから素材と世界の中の UI で上書きする。spec の `shape` フラグの値も併記する（`references/spec-format.md`）。

- **可愛い・元気**（Pop Rink、縁日、おもちゃ箱）: 角丸 16〜26 px、ピルの CTA、太いインクの縁 3 px、艶と下縁あり、CTA や見出しを −2〜−4° 傾ける（2〜3 要素まで）、押すと縮んで Back で戻る、キャンディ 4〜6 色、マスコット可、丸い書体。フラグは既定のまま。
- **かっこいい**（レース、SF、ストリート）: 角 0〜6 px、斜めの切り欠き、縁は細く硬いか無し、艶なし（金属なら細いハイライト線 1 本）、押下は明度変化か数 px のずれ（`press: "none"` にして自前で）、無彩色＋差し色 1〜2、硬い・細長い・SF の書体、キビキビ（Quad 0.1 s）。`gloss:false, lip:0, textOutline:false, tilt:0`。
- **怖い**（廃墟、呪い、ゾンビ）: 面は暗く、モチーフ固有の色相（錆、乾いた血、病的な緑、苔、黄ばんだ紙）、縁は不揃い・欠け・染み、艶なし、押下は沈むか暗くなる、動きはゆっくり（揺らぎ、滲み、1 Hz 未満の明滅）、不穏な差し色 1 つ、英字にだけ Creepster / SpecialElite / GrenzeGotisch、日本語は太く。子供向けなら怖さは雰囲気（暗さ・音・揺らぎ）で出し、グロ表現は使わない。`gloss:false, lip:0, tilt:0, press:"none"`。
- **上品**（高級ホテル、宝飾、オペラ）: 余白を広く、細い不透明の縁（金・真鍮 1〜2 px、二重線）、角 0〜4 px か真円、艶なし（金属は細い線のハイライト）、2〜3 色＋金属色、セリフ体（Merriweather、AccanthisADFStd、RomanAntique、Guru）、ゆっくりしたフェード、マスコット無し。`gloss:false, lip:0, textOutline:false, tilt:0, press:"none", stroke:1`。
- **懐かしい**（ゲーム機、VHS、昭和の駄菓子屋）: その時代の実物の UI（ゲーム機のウィンドウ、テープのラベル、ブリキの看板）を再現する。制約（色数、ドット、角 0、決まった書体）そのものがモチーフ。動きは段階的（コマ送り、Linear、Constant）。ドット系は `corner:0, gloss:false, lip:0, textOutline:false, press:"none"`、書体は PressStart2P（英字）＋太い日本語。
- **静か**（水墨、北欧、禅、雪原）: 余白が主役、縁は無しか極細、色 2〜3（無彩色＋差し色 1）、動きは開閉のフェードだけ、落ち着いた本文書体、CTA は大きさと差し色で立てる。`gloss:false, lip:0, textOutline:false, tilt:0, press:"none"`、単色系なら `allow.monochrome`。

## 3. 世界の中の UI

モチーフの世界に元からある「表示物」を探し、次の 3 か所に割り当てる。これが入ると言い換えテストに通る。

- **CTA**: 押したくなる物。スタートボタンに相当する物がその世界にあるか（発車ベル、保安官バッジ、蝋封、レバー、ガチャのハンドル、計器のスイッチ）。
- **パネル**: 情報を載せる物（手配書、図書カード、カルテ、メニュー表、ウィンドウ、巻物、石板、計器盤）。
- **ナビ（ドック/タブ）**: 並んで選ぶ物（木の看板、背表紙、ロッカー、切符、引き出し、ラジオのプリセット）。

作例:
- 西部劇 → 手配書のパネル / 保安官バッジの CTA / 木の看板のドック
- 宇宙船 → 計器パネル / 警告縞の CTA / ホログラムのタブ
- 図書館 → 図書カードの一覧 / 蔵書印の CTA / 背表紙のタブ
- 駄菓子屋 → ラムネ瓶のバッジ / くじ引きの CTA / 値札のタブ

見つからない部分は汎用の部品に素材（6 節）を着せる。全部を物にしなくてよい。3 つのうち 2 つあれば十分効く。

## 4. 配色レシピ

役割ごとに決める。spec の palette キーは括弧内。

- **インク (`ink`)** — 本文の文字と縁。純黒ではなく、モチーフの色相を混ぜた暗色（プラム、ココア、墨、焦げ茶、深緑）。明るい面が主のモチーフでは暗色、暗い面が主なら明色（5 節）。
- **紙 (`paper`)** — パネルの面。モチーフの素材の色（クリーム、生成り、羊皮紙、大理石、錆鉄、黄ばんだ紙）。`panel` はもう一段強い面、`quiet` は入力欄などの控えめな面。
- **主役 (`primary`)** — CTA 専用。画面で一番目を引く色（明度差か彩度で）。他の用途に使い回さない。
- **アクセント (`candies`)** — モチーフの色数に合わせて 1〜6 色。多いなら色相環で 50° 以上離す。1〜2 色で成立するモチーフ（墨＋朱、黒＋金）なら無理に足さず `allow.monochrome`。名前はモチーフの言葉で付ける（`kingyo`, `brass`, `shu`）。
- **意味色** — `danger`（キャンセル・退出・削除）、`success`（完了・受け取り）。モチーフの色で表してよい（朱の「否」、苔色の「可」）。
- **補助** — `muted`（補足文字。紙に対して 4.5:1 以上）、`disabled`（無効ボタンの面）、`dim`（モーダル背景の暗幕。モチーフ色の暗い洗い）。
- **パステル (`pastels`)** — 一覧の行ボタン用。アクセントを紙へ 75% 寄せた色。静かなモチーフでは紙と同系の淡色でよい。

文字色の規則（`kit:textOn` と board の規則は同一）:
- `shape.textOutline` が有効（既定）: 明るい面（輝度 > 0.82）→ 暗い文字、明るめの面（> 0.65）で小さい文字（< 24 pt）→ 暗い文字、それ以外 → 白文字＋暗い縁取り（太さ = TextSize / 8.5、1.5〜4）。
- 無効: 暗い文字と白のうちコントラストの高い方。縁取りは付けない。
この規則で、どの色の面でも読めることを保証する。個別に文字色を決め始めると必ずどこかで読めなくなる。

## 5. 暗いモチーフ（紺が主題の場合を含む）

深海・ホラー・宇宙・夜の街・洞窟・古城などは暗い面が正解になりうる。そのとき「暗い紺の半透明パネル」にしないための手当て:

- **暗さに固有の色相を持たせる**: 深海は青緑（hue 180〜190）、ホラーは錆・乾いた血・病的な緑、宇宙は紫〜マゼンタ寄りの藍、夜の街は茄子色、洞窟は苔の暗緑、古城は葡萄酒。hue 205〜250 の低〜中彩度の暗色は lint が紺として弾く。
- **明暗の役割を反転させる**: `paper` を暗く、`ink` を明るく（泡色・月光色・蝋燭の象牙）。明るい面の上の文字と縁取りは暗くないと読めないので、`outline` と `onLight` を暗色で別に指定する。
- **光るものは光らせる**: 発光（ネオン、生物発光、蝋燭、モニタ）がモチーフにあるなら、主役とアクセントを高彩度にして暗い面との明度差で光らせる（UIStroke 2 重）。発光の無いモチーフ（廃墟、墨）では光らせない。
- **テクスチャで空白を埋めるか、闇を見せるか**: 泡・星・霧・埃・染みで埋める。静かな暗さ（夜の雪原）なら埋めない。
- **紺そのものがモチーフのとき**（海軍、夜の港、学生服、藍染め、宇宙の制服）: 紺を使ってよい。spec の `allow.navy` に理由を書く。そのうえで「管理画面の紺」にしないために、紺を不透明で深く（半透明にしない）、紺と組む素材をはっきり出す（真鍮の金、白いロープの縁、信号旗の原色、刺繍の太い線、藍の布目の縞）、白は純白ではなく帆布や生成り、差し色はモチーフの物から（信号旗の赤と黄、錨の真鍮）。

## 6. 形・縁・質感（素材から決める）

縁と面の描き方は素材から決める。一律に「太い縁が良い」わけではない。悪いのは「薄く、半透明で、何の素材でもない 1 px の縁」だけ。

- **ステッカー・飴・プラスチック**: インク色の UIStroke（Border）3 px、角丸 16〜26、艶（上 1/3 に白 80% 透明の帯）、下縁（下 6〜9 px を一段暗く、押すと沈む）、真下にずらしたインクの板の影。
- **紙・布・木**: 縁 2〜3 px（焦げ茶や墨）、艶なし、角は小さく、破れ・釘・縫い目・木目の縞で素材を出す。
- **金属・高級**: 細い不透明の金属色 1〜2 px、二重線（外枠の内側にもう 1 本、4〜6 px 内側）、角 0〜4、艶の代わりに上辺だけ明るい 1 px のハイライト、大理石は淡い縞の UIGradient。
- **ドット・ゲーム機**: 角 0、縁は 2〜4 px の不透明、角を 1 マス欠いて階段にする、影なし、グラデーションなし（色は段階で）。
- **墨・筆**: 縁ではなく太さの揺れる筆の帯（傾けた Frame を濃淡で重ねる）、にじみは半透明の大きな丸、朱の印（正方形＋白抜き）を 1 つだけ。
- **ネオン・ホログラム**: 2 重ストローク（太く半透明＋細く不透明）、暗い面、角 4〜8。
- **錆・廃墟**: 縁は欠けた線（複数の短い Frame）、染み（半透明の不定形の丸の重なり）、テープやクリップで留めた紙。

共通:
- **角丸は全部同じにしない**（パネル > ボタン > バッジ）。角 0 のモチーフは全部 0 でよい。
- **傾き**: 手貼り感のあるモチーフ（ステッカー、手配書、メモ）で 2〜3 要素まで。機械・高級・ドットでは傾けない。
- **柄**: 縞（UIGradient のキーポイントで 10 本まで）、ドット（Frame の格子）、走査線（細い縞を半透明で）。
- **影**: 真下へ 4〜6 px ずらした暗い板（透明度 0.7）。ぼかし影は Roblox では高くつくので使わない。高級・静かなモチーフでは影を無くして余白で浮かせる。

## 7. 字

書体は `references/fonts.md` の実在一覧から選ぶ。組み合わせの型:

- **声になる見出し（display）**: モチーフの声。多くは英字専用（LuckiestGuy、Bangers、Creepster、PermanentMarker、Fondamento、GrenzeGotisch、Michroma、PressStart2P、SpecialElite）。日本語が入る文字列には使わない（`latinOnly`）。
- **見出し・ボタン（title / button）**: 丸く太い（FredokaOne）、硬く太い（DenkOne、Oswald、Sarpanch）、セリフ（Merriweather、AccanthisADFStd）、細身の幾何（JosefinSans）。Bold 以上を要求する。
- **本文（body / strong）**: 読みやすさ優先（Nunito、BuilderSans、Montserrat、TitilliumWeb、Ubuntu、Merriweather）。Bold / Heavy。

日本語の UI では画面の文字の大半がシステムの日本語書体で描かれる。だから日本語の印象は「太さ」「大きさ」「字間」「縁取りの有無」「色」で作る。英字の飾り書体は CTA・モード名・数字などの短い英字に効かせる。和風のモチーフで英字を置かないなら、声は日本語の大きさと配置（縦書き風の積み、余白）で出す。

## 8. アイコン・マスコット・小物

- **絵文字アイコン**: 画像アセット無しで色付きアイコンが出る。系統を揃える（モチーフの物で統一）。TextSize の約 1.5 倍の箱に入れる（22 pt → 36 px）。絵文字のカラフルさがトーンに合わない（上品・静か・ドット）なら、記号（▶ ◆ ✕ ★）やインクで描いた Frame の図形、文字そのもの（「始」）を使う。
- **マスコット**: 丸い Frame の組み合わせ（体・腹・目・瞳・頬・くちばし/ヒレ/耳）で描く。部品は 8〜14 個。置き場所はモーダルの角、ロード画面の進捗バーの上、空の一覧。可愛い・元気なトーンで、モチーフに生き物がいるときだけ。上品・怖い・静かなトーンでは代わりに紋章・影絵・小物を置く。
- **小物**: 看板の形（提灯、札、封蝋、ネオン板、真鍮プレート）、柄（縞・水玉・波・格子）、背景の飾り（ViewportFrame で小さな 3D の情景を置くとモード選択が一気に「ゲームの箱絵」になる）。

## 9. 動き

トーンで選ぶ:
- **弾む**（可愛い・元気）: 押すと 0.08 s で 94% に縮み、離すと Back で戻る。ホバーで 104%。出現は上から落ちながらポップ。
- **キビキビ**（かっこいい）: Quad 0.1 s、横から滑り込む、押下は明度変化。
- **ゆっくり**（上品・静か）: 0.3〜0.5 s のフェードと小さな移動だけ。常時ループは無しか 1 つ。
- **不穏**（怖い）: 揺らぎ（位置と透明度をゆっくり）、滲み、1 Hz 未満の明滅。急な動きはジャンプスケアとして 1 回だけなら可、繰り返さない。
- **段階的**（懐かしい・ドット）: EasingStyle.Constant や短い段階で動かす、カーソル ▶ の点滅は 1 Hz 程度。
- **登場演出**: 要素を画面より大きい状態から縮めない（印やスタンプを巨大化して押すと、その間は画面全体が主役色に染まる）。拡大は元の 1.3 倍まで。

共通: 待機ループは 1 画面 1〜2 個まで。reduced motion（`GuiService.ReducedMotionEnabled` かゲームの設定）ではループを止め、状態変化は即時に適用する。3 Hz 以上の点滅・フラッシュは使わない。

## 10. 作例（トーン違い）

作例は発想の幅を示すためのもの。値をそのまま使わず、投稿されたモチーフから毎回組み立てる。

- LuckiestGuy（英字の CTA）+ FredokaOne（見出し・ボタン）+ Nunito Bold/Heavy（本文）。
- 世界の中の UI: 氷を削ったようなリンクの情景のモードカード、傾いたレモン色のピル型 PLAY、Frame のペンギン。

**縁日（提灯・金魚すくい・りんご飴）** — 元気・和。
- 紙 #FFF6E3（和紙）/ インク #3A1E14（墨茶）/ 主役 #F2502E（提灯の朱）/ アクセント kingyo #FF7A3D・ringoame #E8304F・ramune #3FC6E8・wakaba #58C95A。
- PermanentMarker（英字）+ DenkOne Bold（屋台札の見出し）+ Nunito Bold。
- 世界の中の UI: 提灯型の CTA（上下に墨色の帯）、屋台の暖簾の見出し、団扇のバッジ。

**深海（チョウチンアンコウ・発光クラゲ）** — 暗い・可愛い。

## 11. AI っぽさとハウススタイルの一覧

AI の既定値:
- 紺〜スレートの面に半透明、1 px の水色の縁、細い白文字（紺が主題のモチーフは 5 節）。
- 全カード同寸・同色・同じ角丸、全部に同じ弱いドロップシャドウ。
- 主役の CTA が他のボタンと同じ見た目で、色だけ少し違う。
- 見出しが全部大文字の小さな英字ラベル（"SETTINGS"）で、字の階層が 1 段しかない。
- 色は 2 色（紺＋水色）で、モチーフの物が画面のどこにもいない。
- 意味の無いグラデーション（紫→青）を全面に掛ける。

ハウススタイル（このスキルの作例をどこにでも着せる）:
- どのモチーフでも傾いた黄色いピルの CTA と呼吸する後光。
- どのモチーフでもクリームの紙＋太いインクの縁＋艶＋下縁。
- どのモチーフでもキャンディ色のタイルが並ぶドックと絵文字アイコン。
- 生き物のいないモチーフにも Frame のマスコット。
- 静かなモチーフの余白をドットや縞で埋める。
- 上品・怖いトーンでも押すと弾む。
- どのモチーフでも中央の CTA の背後に放射状の後光。
- どのモチーフでも同じ構図（中央 CTA、下部中央に 4 枠のドック、左上に題字、右上に所持金）。
- どの画面にも英大文字の小さな設定テキスト（"DIG SITE A-7" "WARD 4F"）。効くモチーフもあるが、毎回付けると癖になる。
