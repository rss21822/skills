# 事業演習：短時間就業から採用判断支援へ

本例はユーザーが提示したタイミーの使われ方の解釈を教材にしたものである。
会社の成長史、実際の課金、公式戦略、法制度を確認した資料ではない。
短時間就業を、法律上の試用期間や特定の雇用制度と同じものだと扱わない。
実際の導入条件・労務・料金の確認は別途行う。

## 元の価値
欠員がある企業と、短時間働きたい人を結び、必要な就業を成立させる。
これは企業にも働き手にも有用な価値であり、単なる低価値機能として扱わない。

## 一段上の目的
企業は労働力を確保したいだけでなく、将来も一緒に働ける人を見つけたい場合がある。
働き手も、入る前に仕事内容や職場との相性を知りたい場合がある。
「企業だけが求職者を試す」とせず、双方の判断を分ける。

## 主再定義（H）
短時間の仕事を成立させる過程を、双方が相性を知り、関係を深めるか判断する機会として捉える。

| 項目 | 欠員補充としての定義 | 採用判断支援としての仮説 |
|---|---|---|
| 成果の意味 | 一回の勤務成立 | 相互理解と適切な次の判断 |
| 時間範囲 | 直近の勤務 | 勤務前後と継続関係 |
| 必要な設計 | 募集、応募、就業 | 適切な評価、再依頼、関係継続の導線 |
| 資産 | 稼働に必要な情報 | 適切に扱える実務履歴や相互の希望 |
| 検証候補 | 充足、利用の継続 | 自発的な再就業、判断に使う行動 |

## 再定義か用途拡張か
同じサービスを別の場面で使うだけなら用途拡張である。
相互判断を成果とし、それに必要な情報・導線・評価を組み直すなら問題再定義も含む。
実在の企業がどちらをどこまで行っているかは調査して判定する。

## 必須と代償
必要：双方が目的を理解すること、情報の質、公平な判断、本人の選択、適切なデータ管理。
代償：評価が誤ったラベルとして固定化する、就業目的がずれる、運用負担が増える可能性。
採用支援に寄せすぎて、単発で働きたい人の価値を壊さない。

## 検証
実際の勤務後に双方が関係を続けるか、その経験を判断に使うかを確認する。
肯定的な感想だけで、採用コスト削減や定着率改善を断定しない。
採用転換率のみを最大化せず、不適合に気づいて見送る判断も成果に含める。
