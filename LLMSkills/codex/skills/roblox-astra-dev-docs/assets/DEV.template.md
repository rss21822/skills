文書状態: 今回どこまで具体化したか

<!-- これは執筆用の骨格。説明文・コメントを完成文書に残さない。不要な節は削除する。既存の正本があればその構成を優先する。 -->

## 0. 今回の到達点・再開地点

- 今回作るもの: 入力から結果まで確認できる完成形。
- 今回の範囲: MVPと、ユーザーが明示した重要な除外事項。
- 守る条件: 原案の核、固定した条件、許可された変更範囲。
- 次の作業: 作業IDまたは見出し。必要な仕様節とファイルだけを示す。
- 作業を進める条件: 影響する未確定事項がなければ「なし」。文書作成と実装依頼は区別する。

## 2. 実装構成と契約

対象端末の操作・カメラ・必要な表示、進行状態と遷移条件を示す。

| 場所 | 実在／追加予定 | 責務・管理方法 |
|---|---|---|

通信・共有状態・保存・Place移動など、MVPで使う契約だけをここへまとめる。
境界をまたぐ入出力は型、検証条件、成功・失敗時の結果を示す。共通条件は一度だけ定義する。

### T01: 最初の完成単位

- 目的・参照仕様:
