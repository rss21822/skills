# Quick Input Template

すべてを埋める必要はありません。自由文でも動作します。

```text
【世界観・前提】

【プレイヤーになってほしい存在】

【実現したい感情・幻想】

【頭に浮かんでいる場面】

【必ず入れたい攻撃・能力・乗り物・場所】

【避けたいジャンルや既存パターン】

【参考作品】

【開発上の制約】
```

## 最小入力

```text
この世界観をRobloxゲーム化して：
「________」
一案だけ、必要最小限の設計と一次評価を提示して。
```

## 別カテゴリへの再設計

```text
同じ世界観のまま、前案とは少なくとも
・主要行動
・勝利条件
・セッション構造
の3点が異なるゲームカテゴリで再設計して。
```

## 必須アクション型

```text
次のアクションを必ず採用して：
・________
・________
・________

各アクションに、攻撃範囲、攻略上の用途、非ダメージ効果、隙、誤用リスク、連携用途を与えて。
```
