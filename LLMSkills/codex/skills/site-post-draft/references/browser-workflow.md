# ブラウザ操作と検証

サイトごとのボタン名や保存仕様は、その時点の画面を根拠にする。この資料の例示ラベルを、実際に観測せず使わない。

## 接続

現在の環境で公開されているブラウザツールを使い、その初回手順・操作規則・アップロードの説明を読む。古いローカルSkillに記載されたAPI名より、現在のツール定義を優先する。存在しないツールや、ブラウザの内部HTTP APIを推測して補わない。

`mcp__cua_repl.js` がある環境では、`cua` の初回呼び出し規則に従う。ブラウザ指定があれば従い、指定がなければ対象サイトのログイン済みセッションを優先する。適切な既存セッションがなければ、利用できるブラウザで対象サイトを開く。サイト名しかない場合はまず公式URLを特定する。

タブ一覧の取得は対象選択に必要な範囲で行い、無関係な閲覧履歴やアカウント情報を収集しない。

## 操作

画面を観測し、表示されたラベル・入力欄・状態から次の一手を選ぶ。クリックや入力後は最新の状態を取り直す。古い要素番号を使い回さない。

現在の `cua_repl` で使える方法の例:

- 画面確認: `tab.getAXState()`、必要ならスクリーンショット。
- 編集欄への入力: `tab.setValue(...)`、`tab.paste(...)`、または現在の説明にある `tab.playwright` の入力機能。
- 保存: 観測した下書き保存の操作。単に最後の強調ボタンを押す、フォームをEnterで送信する、といった操作は避ける。

入力前に完成した本文を手元で確定し、入力後の照合元にする。プレーンな入力欄はフィールド値を、リッチテキスト欄は編集可能な範囲と表示結果を確認する。補助ラベルや非表示の複製を本文として数えない。

## 動画ありの場合だけ

現行ブラウザのファイルアップロード説明を読む。現在の環境では、ブラウザの追加説明にある `agent.documentation.get('file-uploads')` から取得できる。APIが変わった環境では現在の説明に従う。

現行 `cua_repl` のファイル選択例。`tab` は選択済みタブ、`videoPath` は確認した絶対パス、`uploadControl` は画面で確認したアップロード欄のlocatorとする。

```javascript
const chooserPromise = tab.playwright.waitForEvent('filechooser', { timeoutMs: 10000 });
await uploadControl.click();
const chooser = await chooserPromise;
await chooser.setFiles([videoPath]);
await tab.getAXState();
```

選択待ちを開始してから欄をクリックする。`locator.setInputFiles` など、この環境で公開されていないメソッドを使わない。ファイルパスをページのJavaScriptへ書き込んだだけで添付したと見なさない。

アップロード完了と変換・検査処理の完了を区別する。処理中なら同じタブ・処理を監視する。時間がかかったことだけを理由に再アップロードしない。明確に失敗した場合は原因を確認し、修正できる通常の方法があれば再試行する。同じ原因で変化がない再試行を繰り返さない。

## 保存の証拠

保存操作後の下書き一覧・状態表示・再オープン結果を使い、次を照合する。

1. 投稿先とアカウント。
2. 意図した本文。タイトル必須ならタイトルも。
3. 動画の有無、ファイル名または対応を確認できるプレビュー、処理状態。
4. 下書き・未公開の状態。予約済み・公開済みと混同しない。

一覧に同じ短い本文があるだけでは、同じ添付まで保存された証明にならない。保存した下書きIDや編集URLがある場合は同じ対象を使う。

## 画面の保持

現行 `cua_repl` では、エージェントが作成したタブは通常、一時的な扱いになる。成果物の投稿画面には `await tab.markDeliverable()`、ユーザーの操作待ちなど後続作業用には `await tab.markHandoff()` を使う。次のターンでも保持が必要なら、そのターンで再度マークする。

保存未確認の投稿画面は閉じない。保持マークはブラウザ終了・クラッシュ・セッション失効からの永続保存を保証しない。保存済み下書きのリンクがない場合は、サイトとタブ名を案内する。

## 制約がある場合

- 保存機能なし: 入力済み画面まで作り、保存済みとの区別を報告する。
- 動画なしで進めない形式: 同じサイトにテキスト形式があるか確認し、利用可能なら選ぶ。なければ素材不足を伝える。空動画や別の動画を勝手に用意しない。
- アカウント不一致・投稿先未特定: 素材の入力前に解消する。
- ツール未接続・認証待ち: 完成した文面を保持し、必要な接続や操作を具体的に伝える。チャット上の草案だけでサイト上の下書きを作ったことにしない。
