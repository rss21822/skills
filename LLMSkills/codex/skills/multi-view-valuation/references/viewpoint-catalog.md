# 視点カタログ

候補から、今回の企画の評価や設計判断を変えるものだけを選ぶ。各行を独立した人物とみなさず、意味のある属性・状況・期待を組み合わせる。すべての群を出力する必要はない。

## 索引と選定の入口

| 群 | この群を読む主な接点 |
|---|---|
| A ジャンル・隣接市場 | 既存の遊びとの共通性、期待する面白さ、乗り換え理由 |
| B 端末・操作・利用条件 | 入力、表示、速度、精度、通信、刺激が体験を左右する |
| C 地域・言語・生活条件 | 言語や文化的前提、対象地域、生活時間、利用制約が関わる |
| D 他者との関係 | 人数、友人、対戦、協力、意思疎通、観戦が価値や障壁になる |
| E 時間と継続 | 満足までの時間、中断、待機、日課、長期進行に特徴がある |
| F 求める満足 | 行動の気持ちよさや報酬が、どの欲求に結び付くか |
| G ルール・負担の好み | 難度、運、損失、公平さ、複雑さ、反復が評価を分ける |
| H 経験段階・参加経路 | 理解、流入、初心者、熟練、離脱、復帰、人口不足が関わる |
| I 支払いと納得 | 収益化・販売内容・予算・支払者が企画の判断に関わる |
| J 周辺の関係者 | 招待、配信、創作、保護者、運営などが価値成立に必要 |
| K 競合・事業・引き算 | 乗り換え、流行、模倣、維持可能性、追加と削除の判断 |

Fは価値の言語化、Aは市場への入口、B〜E/G〜Iは体験が変わる条件、J/Kは拡大・成立・持続への補助線。全部を一つの人気スコアにしない。

## A. ジャンル・隣接市場

次は探索ラベルであり、ジャンル利用者全員の動機を断定しない。カテゴリ名を根拠に市場規模・現在の分類を述べる場合は公式の最新情報を確認する。

| 候補となる利用者 | 企画との接点を探す問い |
|---|---|
| Battlegrounds & Fighting | 攻防、間合い、読み合い、技、上達、勝利 |
| Music & Rhythm | タイミング、リズム、音と動きの一致、精度 |
| Open World Action | 自由移動、戦闘、逃走、世界で起こす出来事 |
| Adventure | 探索、発見、謎、物語、目的を果たす旅 |
| Obby & Platformer | 移動・跳躍、経路選択、失敗と再挑戦 |
| Party & Casual | 短い説明、短いラウンド、共遊、実力差のある集団 |
| Puzzle | 理解、気づき、解法、試行錯誤 |
| RPG | 成長、ビルド、役割、冒険、キャラへの愛着 |
| Roleplay & Avatar Sim | なりきり、見た目、関係性、生活、ペット |
| Shooter | 狙い、位置、射線、遮蔽物、連携 |
| Simulation | 反復・増加、経営、物理、箱庭、乗り物、放置 |
| Social | 共在、会話、居場所、関係の形成 |
| Sports & Racing | 操作精度、記録、駆け引き、チームへの貢献 |
| Strategy | 計画、資源配分、配置、予測、対策 |
| Survival | 危機、備え、追跡、逃走、救助、生還 |
| Shopping | 発見、試用、比較、好みに合う品の選択 |
| Entertainment | 鑑賞、音楽、映像、撮影、見せる行為 |
| Education | 知識・技能の獲得、理解、試行と発見 |
| Utility & Other | 遊び以外の用途を含む、具体的な不便の解消 |

同じ価値への接点がある隣接ジャンルを選ぶ。全ジャンルへの適合を目標にしない。見た目だけ似る場合と、繰り返す行動が似る場合を区別する。

## B. 端末・操作・利用条件

| 軸 | 分けて考える条件 |
|---|---|
| 端末 | デスクトップ、ノートPC、スマートフォン、タブレット、コンソール、VR |
| 入力 | キーボード・マウス、タッチ、ゲームパッド、入力の併用 |
| 操作可能な手・指 | 両手、片手、同時入力の数、連打や長押しの負担 |
| 性能 | 処理性能、メモリ、発熱、バッテリー、安定したフレーム表示 |
| 画面 | 大小、縦横、指による遮蔽、視距離、文字や対象の大きさ |
| 通信 | 遅延、揺らぎ、切断、通信量、遠隔地の友人との接続 |
| 音 | ヘッドホン、スピーカー、無音、騒音下、聞き分け |
| 視覚 | 文字、コントラスト、色だけの区別、動く対象の追跡 |
| 運動・刺激 | 細かな操作、反復負担、カメラ酔い、揺れ、点滅、情報量 |
| 認知・理解 | 読解、複数指示の記憶、注意の切替、画面の優先順位 |
| 利用場所 | 自宅、外出先、移動中、共有空間、音や画面を見せられない場面 |
| 端末の使い分け | 同一端末、場所で切替、家族との共有 |

端末対応の表記だけで操作満足を確認したとしない。特定の実装や補助機能を全企画に要求せず、実際の操作・情報提示との接点を示す。

## C. 地域・言語・生活条件

| 軸 | 分けて考える条件 |
|---|---|
| 国・地域 | 利用環境、対象作品、利用可能性、支払い環境の違い |
| 使用言語 | 母語、第二言語、対応言語を読めない、異言語間の共遊 |
| 言語への依存 | 長文、短文、アイコン、実演、言葉遊び、音声による理解 |
| 文化的前提 | 題材となるスポーツ、遊び、物語、習慣への親しみ |
| 流行の知識 | 元ネタを知る、見たことだけある、全く知らない |
| 時間帯・生活暦 | 放課後、休日、休暇、現地時刻、友人との時差 |
| 年齢・発達 | 操作、判断、読解、対人経験、自己管理の程度 |
| 生活段階 | 学生、就業、育児・介護、自由時間が不規則 |
| 家庭の条件 | 時間制限、保護者の許可、交流や支払いの制約、共用端末 |
| 表現と受容 | 見た目や役割に自分を重ねたい、表現に違和感がある、自己表現を望まない |

国籍、性別、年齢から嗜好を固定しない。意味のある理由がなければ特定の国や人口集団を追加しない。国別の判断には、その違いを説明する実際の資料か検証可能な仮説が必要。

## D. 他者との関係

| 軸 | 分けて考える条件 |
|---|---|
| 参加時の同行者 | 一人、友人一人、数人の集団、途中合流 |
| 望む相手 | NPC、知らない人、友人、相手を問わない |
| 関わり方 | 対戦、協力、同じ場にいる、干渉を避ける |
| 関係の種類 | 親しい友人、家族、初対面、オンラインだけの知人 |
| 実力構成 | 初心者同士、熟練者同士、実力差のある集団 |
| 人数 | ペア、少人数、大人数、途中で人数が変わる |
| 参加の役割 | 探す人、誘う人、誘われる人、遅れて来る人 |
| チーム内の好み | 主役、支援、指揮、守備、自由行動、固定しない |
| 意思疎通 | 無言、合図、定型文、テキスト、音声、異言語 |
| 関係の継続 | その場限り、知人を増やす、固定チームを作る |
| 人前に出る好み | 注目されたい、仲間内で目立ちたい、静かに遊びたい |
| 対人行動への許容 | いたずら、妨害、挑発、助け合い、他者に評価される負担 |

一人参加をソロモード希望に変換しない。友人と入れること、同じ試合で遊べること、脱落後も一緒に楽しめることは別の評価点。

## E. 時間と継続

| 軸 | 分けて考える条件 |
|---|---|
| 一回に使える時間 | 数十秒、数分、十数分、一時間以上 |
| 最初の満足までの時間 | 即時、小さな練習後、長い準備も楽しむ |
| 起動頻度 | 一日に何度も、毎日、週末、気が向いたとき |
| 中断 | 集中できる、頻繁に中断、突然終了が必要 |
| 待ち時間 | 即参加、短い待機、交流しながら待つ |
| 満足の期間 | 一瞬、一試合、今日の成果、数週間の上達、長期蓄積 |
| 遊ぶ時期 | 日常、休日、大型更新、友人が集まるとき |
| 終了 | 一試合で区切る、目標まで続ける、自由に出入り |
| 復帰 | 毎日、数日後、数週間後、数か月後 |
| 習慣への態度 | 日課を求める、任意の参加、義務感を避ける |

短時間の満足と長期の熟達は両立し得る。長期継続の改善を、通貨・デイリー・収集の追加だけに限定しない。

## F. 求める満足

| 軸 | 得たい結果 |
|---|---|
| 操作の快感 | 動く、当てる、滑る、跳ぶ、壊す感覚 |
| 上達 | 工夫によって以前できなかったことができる |
| 勝利 | 相手に勝ち、自分の強さを確かめる |
| 記録 | 他人の勝敗とは別に自己ベストを更新する |
| 思考・理解 | 仕組みを理解し、判断や解法を見つける |
| 発見 | 未知の場所、秘密、組み合わせ、現象を見つける |
| 収集・完成 | 好きなもの、図鑑、セットを揃える |
| 成長・蓄積 | 時間が能力、選択肢、資産、実績として残る |
| 効率化 | 少ない手間や資源でよい結果を出す |
| 力・役割 | 憧れる能力、職業、存在、立場を操作する |
| 創作・表現 | 見た目、建築、動き、戦い方に自分らしさを出す |
| 所属・親密さ | 居場所を持ち、関係を深める |
| 承認・地位 | 努力、実力、センス、貢献を認められる |
| 貢献・世話 | 人を助け、仲間や生き物を育てる |
| 笑い・即興 | 予想外の出来事を起こし、笑い合う |
| 緊張・スリル | 危機、追跡、逆転、ぎりぎりの成功 |
| 安心・休息 | 急かされず、失敗を恐れず落ち着く |
| 没入・物語 | 別世界で過ごし、出来事に感情を動かされる |
| 鑑賞 | 景色、音楽、動き、他者のプレイを楽しむ |
| 自律性 | 目標、順番、行動、遊び方を自分で選ぶ |

「楽しい」「成長したい」だけで終えず、今回の行動と望む結果に具体化する。提供側が意図する価値と、受け手が実際に感じた価値を区別する。

## G. ルール・負担の好み

| 軸 | 分けて考える好み |
|---|---|
| 難度 | 簡単に成功、適度な挑戦、厳しい攻略 |
| 習得の負担 | 説明なし、遊びながら習得、事前の研究・練習 |
| 操作の複雑さ | 少数操作を深く使う、多数操作を使い分ける |
| 主に使う能力 | 反射、精密操作、判断、記憶、計画、創造、対人調整 |
| 運の役割 | 安定した実力勝負、番狂わせ、偶然中心 |
| 公平さ | 同一条件、同程度の技能、成長差を含む勝負、非対称な役割 |
| 失敗の損失 | 即再挑戦、試合のやり直し、資源喪失、長期進行の喪失 |
| 負けの受容 | 原因を理解、笑えればよい、人前の失敗が苦手 |
| テンポ | 常に忙しい、緩急、ゆっくり判断 |
| 目標の明示 | 次の行動まで案内、大目標だけ、自己設定 |
| 選択肢の量 | 少数で迷わない、豊富な選択肢を研究 |
| 反復と変化 | 同条件を磨く、少しずつ変化、毎回異なる展開 |
| 勝敗 | 個人、チーム、全員成功、勝敗不要 |
| 対立 | 直接攻撃、間接競争、協力のみ、対立回避 |
| 雰囲気 | かわいい、格好よい、滑稽、穏やか、不気味、現実的、抽象的 |
| キャラクターとの関係 | 自分のアバター、固定主人公、選択キャラ、姿を重視しない |
| 物理感覚 | 正確で予測可能、重さ・慣性、大げさで意外性がある |

両端を全員向け設定で吸収する前に、中心の面白さに必要な選択を検討する。

## H. 経験段階・参加経路

| 軸 | 分けて考える段階・条件 |
|---|---|
| Roblox経験 | 初めて、慣れている、長年の経験、他プラットフォーム中心 |
| ジャンル経験 | 未経験、類似作経験、競合の熟練者 |
| 作品との関係 | 未認知、発見直後、初回、数回目、常連、休眠、復帰 |
| 発見経路 | 検索、おすすめ、友人招待、動画・配信、広告、コミュニティ |
| 来訪目的 | 特定の遊びを探す、何となく探す、誘われたから来る |
| 参加前の期待 | タイトル・画像・紹介で想像する体験と、最初の体験の一致 |
| 学び方 | 実演、試行、説明、友人、攻略情報 |
| 競合への愛着 | 乗り換え、併用、友人・蓄積・熟練があるため離れにくい |
| 不参加・離脱 | 興味不足、理解困難、重さ、待ち、恐怖、不公平感 |
| 再訪 | 上達、続き、友人、新要素、習慣、イベント、居場所 |
| 人口条件 | 一人、少人数、十分な人数、急増、地域・時間帯による不足 |
| 上達後 | 初心者の楽しさ、中級者の目標、熟練後の深さ |

人気作を遊び続ける人だけで代表させない。失敗を予測しただけなら、観測済みの離脱理由として書かない。

## I. 支払いと納得

| 軸 | 分けて考える条件 |
|---|---|
| 支払い意向 | 無料、気に入れば購入、予算を確保して参加 |
| 予算・頻度 | 少額を時々、一定予算、記念日、支出を避ける |
| 支払者 | 本人、保護者、家族、友人からの贈与 |
| 購入対象 | 見た目、表現、追加体験、創作、利便、応援 |
| 価格への納得 | 比較、試用、長期利用、内容の理解 |
| 非購入者 | 参加、貢献、上達、交流への納得 |
| 購入後の満足 | 直後の満足、繰り返す価値、内容変更後の価値 |
| 贈与・共有 | 贈る、一緒に使う、見せる、購入を隠したい |

楽しさの強さと支払意向を同一視しない。未成年者の制約や焦りを利用する提案を改善とみなさず、価値と納得を評価する。

## J. 周辺の関係者

| 関係者 | 企画との接点 |
|---|---|
| 誘う人 | 一言での説明、合流、相手を待たせない |
| 誘われる人 | 予備知識なしの参加、自分にもある役割 |
| 配信者 | 見せ場、判断、反応、視聴者との関係 |
| 動画・短尺制作者 | 短い映像で分かる状況・面白さ |
| 観戦者 | 何が起き、何が優れているかの理解 |
| 攻略・解説制作者 | 研究、比較、教える価値 |
| コミュニティ運営者 | 大会、集まり、共同目標、初心者支援 |
| ファン創作者 | 絵、物語、映像、解釈を作る余地 |
| 保護者・同伴者 | 内容、交流、支出、終了のしやすさへの納得 |
| モデレーター・サポート | 問題の把握、対処、日常の運営負担 |
| 制作・運営者 | 約束した体験の制作、保守、更新 |
| 事業の評価者 | 届く人数、獲得、継続、収益、運営費 |

関係者はプレイヤーの動機と別に扱う。宣伝できそうという理由だけで配信機能を足さない。

## K. 競合・事業・引き算

| 視点 | 比較する問い |
|---|---|
| 直接競合の利用者 | 既存作に加えて時間を使う理由があるか |
| 隣接ジャンルの利用者 | 好きな価値を保ったまま新しい遊びに入れるか |
| ジャンルを避ける人 | 避ける理由を軽減すると関心が生まれるか |
| 既存作に不満がある人 | 不満を解消できるか。代わりに失う魅力は何か |
| 既存作に満足する人 | 追加の価値、併用する理由があるか |
| 流行が去った後 | 題材の新しさや露出がなくても残る価値は何か |
| 少人数での運営 | 更新量、制作量、管理負担を維持できるか |
| 模倣された後 | 操作感、関係性、蓄積、運営、世界観に選ぶ理由が残るか |
| 追加した場合 | 得する相手と、複雑さ・待ち・負担で損をする相手は誰か |
| 削除した場合 | 入口・理解・品質が改善する相手と、魅力を失う相手は誰か |

競合と違うこと、供給が少ないこと、模倣に手間がかかることだけでは需要や優位性を証明できない。価値を受け取る相手と、成立条件へ戻して評価する。
