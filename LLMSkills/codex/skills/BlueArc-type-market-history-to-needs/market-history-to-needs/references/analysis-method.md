# 共通要素・主流の偏り・持続的ニーズの分析

以下はこのSkillの分析規約であり、ヒット予測を保証するモデルではない。

## 1. 最初に分ける4つの観察

| 観察 | 確かめること | それだけでは分からないこと |
|---|---|---|
| 供給 | 同じ要素を持つ作品が多数発売・運営される | その要素にプレイヤーが集中するか |
| 集中 | その作品群に活動が多く集まっている | その要素を理由に選ばれたか |
| 選好 | その要素が評価される反応や選択がある | 全ユーザーに同じ効果があるか |
| 効果 | 比較によりその要素の影響を検討できる | 他時代・他市場でも同じ因果か |

このSkillの既定の到達点は、公開資料による記述と比較に基づく解釈である。観察研究を因果実験の結果のように書かない。

## 2. 特徴の分類表を作る

作品を読む前に大枠を設定し、少数の探索例で定義を調整し、その後は同じ規約で判定する。後から都合のよい基準へ変えたら変更と再判定を記録する。

### 候補となる軸

| 分析層 | 調べる候補 | 根拠の種類 |
|---|---|---|
| 題材 | 学園、生活、軍事、スポーツ、ファンタジー、既存IP等 | 世界・人物・公式設定 |
| 調子 | 明るい、緊迫、重厚、穏やか、滑稽等 | 色だけでなく出来事・音・会話も含む |
| 中心行動 | 戦う、集める、作る、解く、育てる、演じる等 | 代表的な通常プレイ |
| 選択 | 技量、判断、配置、運、資源配分、自動進行等 | 何で結果が変わるか |
| 関係 | 競争、協力、共在、役割分担、人物との交流等 | 参加と関係の構造 |
| 時間 | 短ラウンド、長期育成、継続世界、待ち時間等 | セッションと長期構造を別にする |
| 成果 | 勝利、上達、収集、物語進行、表現、承認等 | 行動と報酬の対応 |
| 参加負担 | 操作、説明、知識、時間、金銭、心理等 | 入口と継続を分ける |
| 供給条件 | 端末、入力、価格、運営更新、推薦、IP等 | 現行の仕様・公表情報 |
| 受け取る価値 | 気兼ねなさ、親しみ、緊張、達成、所属等 | プレイヤー反応と解釈を区別 |

全軸を機械的に採用しない。市場の差を説明できない軸は捨て、固有の軸を加える。
「明るい／重い」「関係／達成」は必ずしも排他的ではない。一作品が両方を持つ場合は文脈別に記録する。無根拠な二軸座標や数値スコアへ押し込まない。

### 判定の単位

作品全体、主モード、代表的なセッション、ストーリーなど、単位を明記する。
例：一つの期間イベントだけにある仕組みを、作品全体の中心要素と判定しない。
実プレイ、動画確認、公式説明、第三者記事のどれで確認したかを残す。プレイしていないなら手触りを実感したように書かない。

### 判定コード

- `present`：定義した中心的条件を満たす。
- `partial`：一部のモード・場面・対象者で満たす。具体的範囲を書く。
- `absent`：十分に観察でき、その条件が該当しない。
- `unknown`：観察・資料不足で決められない。
- `not_applicable`：その分類が作品へ適用できない。

元の判定と理由を残し、集計時のルールを開示する。

## 3. 共通性を集計する

### 作品数の頻度

全採用作品数、要素ごとの確認可能数、採用数、部分採用数、不明数、非該当数を分ける。

**架空の計算例（実市場のデータではない）**：10作品中、`present=6 / partial=1 / absent=1 / unknown=2` なら、
「10作品のうち6作品で中心的に確認、1作品で部分的、2作品は未確認」と書く。
割合を使うなら、分母を明示して「確認可能8作品に対し中心的採用6作品」とし、未確認2作品を隠さない。

複数要素の組み合わせは、それぞれの観測が揃った作品集合で計算する。要素Aの採用数と要素Bの採用数を足して、A+Bが主流と結論しない。

### 重み付きの共通性

比較可能な活動指標がある場合に限り、その群で要素を持つ作品の活動量構成比を出せる。
作品数では少数でも、活動量では支配的な群があり得るので、両方の観察を分ける。
欠測作品は0として重み付けしない。算出に使えた群と対象外を表示する。

### 系列・IPによる偏り

同じ系列の続編や類似作が多数あるときは、系列単位でまとめた定性的比較も作る。
同一IPの多数作品でしか成立しない共通性は、そのIPの特徴かもしれない。市場全体へ広げる前に他系列を探す。

### 感度の確認

必要な比較だけを行う。
- 一時的なイベント急増作を除いても結論は同じか。
- 最大の1作品を除くと傾向が消えないか。
- シリーズ単位で見ても同じか。
- 地域・端末・既存作／新作で違わないか。
- 判定が曖昧な作品を保留すると結論が変わらないか。

変わる場合は、弱い結論を隠すのではなく「特定群に限られる傾向」として報告する。

## 4. 偏りは、比較のある文章で書く

### 偏りカード

```text
B-ID：
解釈：
対象市場・期間・地域・対象者：
現在の支持例と根拠：
共通性の集計対象・判定規約：
比較基準（過去／現代周辺／別の下位市場）：
相違する方向の成功例：
変化の方向と始点：
供給側の説明：
需要側の説明：
IP・広告・ネットワーク等の交絡候補：
持続性（定着／短期／判定不能）：
範囲の感度：
信頼度と残る疑問：
```

### 言い方の境界

- 可：「観測できた上位群ではAが共通する。過去のB中心の代表群とは異なる」。
- 条件付き：「対象地域の直近期間ではA方向への集中がある」。比較可能な活動データと対照が必要。
- 不可：「Aが売れるから全社がAにした」。制作意図と売上因果の両方を推測している。
- 不可：「Aに偏っているので非Aが次の大ヒットになる」。空白への需要は未検証。

複数の主流が並存するなら、無理に一文へ統一しない。「地域XではA、地域YではB」「上位長寿作と新興作では異なる」と分けて結論する。

### 三つの説明を必ず分ける

1. 何が起きているか：観測された作品群と値。
2. どう解釈するか：共有される体験と方向。
3. なぜ起きた可能性があるか：需要・供給・環境の競合する説明。

## 5. 普遍的ニーズは、表現を変えて照合する

### 抽象化の階段

**架空の例（実市場の結論ではない）**：

```text
表面：キャラクターから返信が届く。
仕組み：継続した関わりに応じて反応・会話が変わる。
プレイヤー行動：反応を確かめるために再訪する。
価値の仮説：自分の関わりが相手に認識され、関係が深まる実感を得たい。
```

一段ずつ根拠の有無を示す。再訪だけから「愛されたい」という内心を確定しない。
同じニーズが、別時代の手紙、会話、生活の共有など別の形式でも確認できるかを調べる。例示した形式が実際に歴史上支持されたかは別途検証する。

### 具体性の目安

弱すぎる記述：楽しい／成長したい／つながりたい。
狭すぎる記述：ガチャを引きたい／特定の絵柄が欲しい／毎日ログインしたい。
目指す記述：**［特定の状況にある人］が、［望む状態への変化］を、［重視する条件］のもとで経験したい。**

欲求・仕組み・消費行動を区別する。収集を好む場合も、完成、発見、自己表現、知識の整理など、求める価値が同じとは限らない。

### 各ニーズを検査する質問

- 現在だけでなく初期・中期にも根拠があるか。
- 同一IPの継続ではなく独立した作品にもあるか。
- 題材・端末・ゲーム構造を変えても似た価値が確認できるか。
- 制作者の意図だけでなく、ユーザー反応や行動と整合するか。
- その価値を支持しない人や、逆の体験を求める群もいるか。
- ノスタルジー、既存ファンの惰性、流通上の選択肢不足でも説明できないか。
- 時代間の空白は、消滅、弱化、移転、単なる史料不足のどれか。
- 同じ言葉を使うだけで、異なる時代の価値を同一視していないか。

### 持続性の種類

| 状態 | 記述 |
|---|---|
| 継続 | 複数時代にわたり反復して確認できる |
| 再来 | 中間で目立たなくなり、後に再び現れる |
| 置換 | 題材・形式・媒体が変わって似た満足が確認できる |
| 同系列内 | 主として一系列・一世代で続いており一般化に限界がある |
| 不明 | 似ているが、時代間の証拠が弱い |

これらは併存してよい。「再来」を空白なく続いていたことにしない。

### 信頼度

- `high`：対象市場・期間内で、複数時代・異なる形式・独立作品と反応の根拠が整合し、主要な反証も検討した。
- `medium`：複数時代で整合するが、反応が少ない、資料が回顧中心、対象群が狭いなどの制約がある。
- `low`：少数作品、同一系列、形態の類似や作り手の意図が中心。候補として残す。
- `unknown`：必要な証拠を得られず判断不能。

これは計算された成功確率ではなく、証拠の質と適用範囲の評価である。高信頼度でも世界全体への普遍性を意味しない。

## 6. 現在との照合で止める

ニーズごとに「現在どう満たされているか」を整理する。
供給が多いか、特定の層しか利用しにくいか、別形式で提供されるか、不明かを記録する。
不満、離脱、代替行動の証拠なしに、供給の少なさだけから潜在市場規模を推計しない。
最後まで分析に徹し、ユーザーが求めていない逆張り案・MVP・実装計画を追加しない。
