# 非公開本番リリース設定・検証記録

必要な項目だけ記録。各項目に「意図値 / 保存済み値 / 根拠 / 未確認」を分ける。未設定を推奨値で埋めない。

## 対象と版

- 本番所有者・グループ、Universe ID、入口Place ID、サブPlace ID/役割、ステージングとの区別。
- ローカル正本、Git/未保存状態、各PlaceのSHA-256、ビルド/テスト結果。
- 各PlaceのCloud公開済みバージョンと時刻。ビルド後のソース差分、Studio接続先のPlaceVersion、APIで未更新のインスタンス種別の有無。
- 一時資格情報を使った場合は用途・範囲・失効確認のみ。値は記録しない。

## Creator Hub設定

- Audience=PrivateとAccessを別々に再確認。入口、サブPlaceの直接入場ポリシー。
- 最低年齢、地域、端末、料金、プライベートサーバー、各Place定員。設定上のAll Agesと実際の16歳未満への配信可否は別判定。
- ジャンル、タイトル、説明、アイコン、詳細サムネイル、ホームサムネイル、ゲームプレイ動画。動画不可なら理由を記録。
- 質問票の評価と地域別不適合。コード上の対策と公開済みPlayer挙動を照合し、未実施の検証を「準拠」と書かない。
- SNSリンクは保存後にゲームページで確認。Discordは有効な招待リンクを使い、`/channels/...`を招待URLとして代用しない。

## 収益

- 開発者製品/パス: ID、所属Universe、販売状態、管理価格設定、ベース価格、ゲーム内表示、購入プロンプト、レシート付与。
- `PriceInRobux`と管理画面価格が違う場合、ユーザー向け割引/地域価格の可能性を調べる。根拠なしにバグとも正常とも断定しない。
- 取引履歴はExperience名・日時・状態・クリエーター受取額を照合。pending、available、グループ配分を別表示。購入未実施なら実収益導線は未検証。

## 実機受入と判定

- Creator Hub保存/履歴、Roblox.comページ、Studio Edit/Play、Roblox Player、スマホ/タブレットを異なる証拠として記録。
- 通常の入口経路、全モード、NPC補充/Teleport、3D描画、HUD、試合継続、Result表示・滞在・操作、帰還/再試合。
- 権限付きアカウントだけの非公開入場は、一般ユーザー到達の証拠ではない。
- 結論は `完了 / 未完了 / 不一致 / 検証不能` を分ける。一般公開ブロッカーと、任意の改善項目を区別。
